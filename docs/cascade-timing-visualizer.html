核心问题

Core 引擎的一次 Tick() 里，匹配、消除、下落、补充瞬间同时完成。 但玩家期望看到：消除播完 → 方块下落 → 新方块补充 → 触发连锁。

Choreographer 的级联时序系统通过三层机制解决这个问题：

1. _columnDestroyEndTimes — 每列消除结束时间字典，让下落等消除播完
2. _columnMoves 追尾计算 — 让同列多个方块瀑布式依次启动
3. CellLock 反馈 — 把动画时序反写回物理层，阻止过早下落
