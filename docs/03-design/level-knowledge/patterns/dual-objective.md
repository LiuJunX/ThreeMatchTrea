# 双目标组合设计技巧

## 三种组合类型

### 1. 同向目标（推荐度: ★★★）

两个目标在操作上自然协同，完成一个自然推进另一个。

| 组合 | 机制 |
|------|------|
| 收集红色 + 清除 Ice | 消除红色方块同时破冰 |
| 清除 Box + 清除 Cage | 炸弹波及两者，一举两得 |
| 清除 Obstacle + 收集 Plate | 清除 Cupboard 释放 Plate |

**设计要点**：
- 步数只需覆盖较难的那个目标
- 体验流畅，玩家感觉"做一件事两个进度"

### 2. 中立目标（推荐度: ★★☆）

两个目标互不干扰，需要玩家分配注意力。

| 组合 | 机制 |
|------|------|
| 收集红色 + 收集蓝色 | 两种颜色需要分别关注 |
| 清除 Ice + 清除 Box | Ice 在一个区域，Box 在另一个 |
| 收集色块 + 达到分数 | 分数自然积累，但需注意 |

**设计要点**：
- 步数 = 目标A步数 + 目标B步数 × 0.7（有重叠操作）
- 将两个目标分布在棋盘不同区域，制造"空间规划"挑战

### 3. 冲突目标（推荐度: ★☆☆，谨慎使用）

完成一个目标会阻碍另一个目标。

| 组合 | 冲突机制 |
|------|---------|
| 收集红色 + 有 ColorBox(红) | 消除红色也在消耗 ColorBox 所需的红色 |
| 清除 Cage + Cage 保护着目标方块 | 清除 Cage 可能导致方块掉落移位 |

**设计要点**：
- 仅用于高难度/Boss 关
- 必须确保在理论上可同时完成
- 步数需要额外余量

## 目标数量与阶段

| 阶段 | 最大目标数 | 说明 |
|------|-----------|------|
| Tutorial (1-10) | 1 | 只有收集色块 |
| EarlyGame (11-30) | 2 | 首次引入双目标 |
| ObstacleIntro (31-55) | 2 | 可以是障碍+色块 |
| MidGame (56-90) | 2 | 组合更丰富 |
| Advanced (91-140) | 3 | 首次引入三目标 |
| Expert (141-200) | 3 | 复杂组合 |

## 设计检查清单

- [ ] 两个目标之间是同向还是中立？（避免无意中冲突）
- [ ] 步数是否考虑了双目标的总消耗？
- [ ] 玩家能否清楚看到两个目标的进度？
- [ ] 是否可以先完成一个再完成另一个？（而不是必须交替进行）
