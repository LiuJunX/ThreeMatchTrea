# 教学关设计模板

## 设计目标

教学关的唯一目标是让玩家**理解一个新机制**。通关是手段，不是目的。

## 核心原则

1. **单一焦点**：一关只教一个概念
2. **必然触发**：设计让玩家一定会用到新机制
3. **容错空间**：步数多 50%，颜色少 1 种
4. **即时反馈**：用了新机制立刻看到效果

## 模板参数

| 参数 | 教学关 | 普通关 |
|------|--------|--------|
| 棋盘 | 7×7 或 8×8 | 8×8 - 9×9 |
| 颜色 | 4 色 | 5 色 |
| 步数 | 目标值 ×1.5 | 目标值 ×1.3 |
| 目标 | 1 个，直接与新机制相关 | 1-2 个 |
| 障碍 | 只有新引入的那种 | 混合 |

## 新元素引入清单

当引入新元素 X 时：

1. **数量少**：3-5 个 X，让玩家逐个处理
2. **位置集中**：放在中央区域，容易接触
3. **最低 HP**：X 只有 1 层
4. **无其他干扰**：没有其他障碍物分散注意力
5. **目标就是它**："清除 N 个 X"

## 示例：Box 引入关

```
关卡号: 31（ObstacleIntro 阶段第 1 关）
棋盘: 8×8 rectangle
颜色: 4
步数: 25
目标: 清除 5 个 Box
Box: 5 个，1HP，集中在中央 3×3 区域
其他障碍: 无
```

## 常见错误

- 新机制 + 另一个新机制 → 信息过载
- 教学关也追求难度 → 失去教学意义
- 新机制放在角落 → 玩家可能根本没注意到
- 没有明确目标指向新机制 → 玩家通关但没学到东西
