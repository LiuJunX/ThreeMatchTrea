# Boss 关设计模板

## 设计目标

Boss 关是阶段性检验——测试玩家是否掌握了当前阶段的所有机制。应有仪式感，但不能不公平。

## 核心原则

1. **综合检验**：用到当前阶段已解锁的多种元素
2. **多目标**：2-3 个目标，考验全局规划
3. **步数公平**：紧张但可完成，目标胜率 40-60%
4. **视觉冲击**：棋盘丰富，元素种类多，一眼就知道是 Boss

## 模板参数

| 参数 | Boss 关 | 普通关 |
|------|---------|--------|
| 棋盘 | 9×9 | 8×8 - 9×9 |
| 形状 | 非 rectangle（cross/diamond/hourglass） | 多种 |
| 颜色 | 阶段上限 | 阶段中间值 |
| 步数 | baseMoves × 1.0 | baseMoves × 1.3 |
| 目标 | 2-3 个 | 1-2 个 |
| 障碍种类 | 2-3 种混合 | 1-2 种 |

## 设计模式

### 围攻模式
- 边缘一圈高 HP 障碍（如 Ice×3 + Box×3）
- 中央放核心目标
- 玩家需要由外向内层层突破

### 分区模式
- 棋盘分 2-3 个区域（L-shape / compartment）
- 每个区域有不同类型的障碍
- 目标分布在各区域

### 逐层剥离
- 多层覆盖：Ground(Ice) + Cover(Cage) + Obstacle(Box)
- 需要按层级逐步清除
- 非常适合作为阶段总结

## 里程碑关卡参考

| 关卡 | 定位 | 预期使用元素 |
|------|------|-------------|
| 10 | 首个 Boss | 纯色块 + 复杂形状 |
| 30 | Early Game Boss | Ice + Cage + 双目标 |
| 55 | Obstacle Boss | Box + Bush + Chain + Grass |
| 90 | MidGame Boss | Safe + ColorBox + Honey + Bubble |
| 140 | Advanced Boss | 全元素混合，三目标 |
| 200 | Final Boss | 最高难度，compartment 地形 |

## 常见错误

- 不公平的 RNG 依赖 → 胜率过低
- 目标太多太杂 → 信息过载
- 障碍铺太满 → 无操作空间
- 没有"开口"让玩家开始行动 → 开局就卡住
