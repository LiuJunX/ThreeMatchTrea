# 难度调节手段总览

## 调节优先级（成本从低到高）

| 优先级 | 手段 | 影响范围 | 调节精度 |
|--------|------|---------|---------|
| 1 | 步数 | 仅时间压力 | 高（±1步可感知） |
| 2 | 颜色数 | 全局匹配概率 | 中（±1色显著） |
| 3 | 目标数量/值 | 完成条件 | 中 |
| 4 | 障碍物数量/HP | 局部难度 | 低（需配合位置） |
| 5 | 棋盘形状 | 全局流动性 | 低（改动成本大） |

**原则**：先调步数，最后调地形。

## 各手段详解

### 步数

- 最敏感的旋钮：±2 步可以显著改变胜率
- 步数充裕 → 容错空间大 → 玩家从容
- 步数紧张 → 每步都重要 → 紧张感
- **宁多勿少**：剩余步数转化为奖励分，体验好

### 颜色数

- 4→5色：匹配概率下降约 20%
- 5→6色：匹配概率下降约 25%
- 6→7色：几乎无自然匹配
- 少色+多障碍 vs 多色+少障碍：前者偏爽快，后者偏策略

### 目标

- 单目标：聚焦，适合教学和简单关
- 双目标（同向）：自然协同（如清 Ice + 收集 Ice 下的方块）
- 双目标（分散）：分配注意力
- 三目标：高复杂度，仅限后期

### 障碍物

- 数量：更多障碍 = 更多 HP 消耗 = 需要更多步
- HP：多层障碍的难度非线性增长（3层 ≈ 1层的 2.5 倍）
- 位置：边角远比中央难清除
- 免疫匹配（Safe/Stone/Owl）：难度贡献 >> 普通障碍

### 棋盘形状

形状通过控制可用空间和连锁流来影响难度：
- **Rectangle**：最简单，流动均匀
- **Cross**：中等，中央汇聚
- **Diamond**：中高，边角多死角
- **L-shape**：中等，分区
- **Hourglass**：高，中间瓶颈
- **Compartment**：最难，独立区域各自为战

## 难度公式（供 Generator 参考）

```
baseMoves = Σ(障碍HP × 1.2) + Σ(CoverHP × 1.0) + Σ(GroundHP × 0.8) + 基础余量(8)
推荐步数 = baseMoves × 难度系数
```

| 定位 | 系数 | 目标胜率 |
|------|------|---------|
| 简单 | ×1.5 | 85-95% |
| 普通 | ×1.3 | 70-85% |
| 困难 | ×1.1 | 55-70% |
| Boss | ×1.0 | 40-60% |

## 分析管线的角色

生成后必须用 `LevelAnalysisService` 验证实际胜率。如果偏离目标：
1. 先调步数（最快）
2. 再调颜色/目标
3. 最后调障碍布局
