# 掉落与连锁设计

## 核心机制

消除后，上方方块在重力作用下掉落填补空位。新方块从 Spawner 行生成。掉落后如果形成新的匹配，触发连锁（Cascade）。

## 关卡设计要点

### 棋盘高度 = 连锁潜力

- **高棋盘**（≥9 行）→ 掉落距离长 → 连锁概率高 → 爽快感强
- **矮棋盘**（≤7 行）→ 掉落距离短 → 连锁少 → 更可控、更策略

### 连锁数量与体验

| 目标体验 | 平均连锁/步 | 设计手段 |
|----------|-------------|----------|
| 爽快 | 1.5-2.0 | 高棋盘 + 4色 + 多生成点 |
| 平衡 | 1.0-1.5 | 标准棋盘 + 5色 |
| 策略 | 0.5-1.0 | 矮宽棋盘 + 6色 + 瓶颈地形 |

### 连锁过多的问题

- 玩家感觉像老虎机，策略感低
- 随机性过大，分析管线难以稳定评估
- **解法**：增加颜色、缩短棋盘、用瓶颈打断连锁流

### 连锁过少的问题

- 枯燥，缺少惊喜
- 步数消耗快，容易卡关
- **解法**：减少颜色、加高棋盘、使用矩形地形

## Spawner 设计

- 每个可到达区域**必须有 Spawner**，否则消除后无法补充
- Compartment 地形要特别注意：两个房间各自需要自己的 Spawner 列
- 不要用障碍堵住 Spawner 行——会导致生成堵塞

## 与其他元素的交互

- **Honey**：粘住方块阻止掉落 → 中断连锁流
- **Bubble**：跟随方块掉落 → 不影响连锁
- **Obstacle**：占据格子 → 减少掉落空间 → 减少连锁

## 设计检查清单

- [ ] 每个连通区域都有 Spawner？
- [ ] 连锁水平与目标体验匹配？
- [ ] Spawner 行没有被障碍堵死？
- [ ] 瓶颈地形的连锁流是否可接受？
