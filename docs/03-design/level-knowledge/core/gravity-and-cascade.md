# 掉落与连锁机制

做关前必读。Tile 如何下落、何时斜滑、什么阻挡移动、cascade 如何触发。

---

## 1. 基本掉落

消除后，上方 tile 在重力作用下向下掉落填补空位。新 tile 从每列最顶部的非 Void 格生成。掉落后如果形成新的 3+ 匹配，触发连锁（cascade）。

**掉落方向**：始终向下。不支持向上、向左、向右的重力方向。

---

## 2. 斜滑机制

当 tile 正下方被**障碍物或不可移动的 tile**阻挡时，tile 可以斜向滑入相邻列的空位。

### 触发条件（全部满足才斜滑）

1. **正下方被阻挡**：下方格子有障碍物，或有不可移动的 tile（被 Cage 等锁住）
2. **目标是死区**：斜向目标格子是"死区"——即该位置无法从上方 Spawner 获得正常填充
3. **目标格子可用**：目标格子为空，无障碍，且本帧未被其他 tile 占用
4. **无竞争**：同列上方没有其他 tile 正在落向该目标

### 死区判定

一个格子是"死区"如果：
- 从该格子向上一直到顶部，路径中有障碍物或不可移动 tile 阻挡
- 意味着 Spawner 的 tile 永远到不了这个位置

### 方向选择

- 如果左右两侧都可以斜滑，**随机 50/50 选择**
- 每帧列处理顺序也随机化（Fisher-Yates），防止左右偏向

### 设计影响

- 障碍物下方的"死区"会被斜滑填充，不会永久为空
- 但斜滑依赖相邻列有多余 tile，不能保证 100% 填充
- **Cage 下方会产生死区**——被 Cage 锁住的 tile 不会下落，下方空位只能靠斜滑填充

---

## 3. 什么阻挡重力

| 阻挡因素 | 效果 |
|---------|------|
| **障碍物（Box、Safe 等）** | 完全阻挡，tile 无法通过。触发斜滑 |
| **Cage（静态 Cover）** | 锁住 tile 不下落，下方产生死区 |
| **Honey** | 粘住 tile 不移动，下方产生死区 |
| **Frost** | 冻住 tile 不移动（允许匹配但不允许移动） |
| **Void 格子** | tile 穿越（不阻挡），到达 Void 下方的格子 |
| **Wall 格子** | 完全阻挡 |
| **CellLock（临时锁）** | 阻止 tile 进入该格子 |

---

## 4. Cascade（连锁）

### 触发

tile 下落后的新棋盘状态被检查匹配。如果有新的 3+ 匹配，继续消除 → 继续掉落 → 继续检查。直到没有新匹配为止。

### 影响因素

| 因素 | 对 cascade 的影响 |
|------|-----------------|
| 棋盘高度 ≥9 行 | cascade 多（掉落距离长） |
| 棋盘高度 ≤7 行 | cascade 少（更可控） |
| 颜色数少（3-4 色） | cascade 多（匹配概率高） |
| 颜色数多（5-6 色） | cascade 少 |
| 瓶颈地形 | 打断 cascade 流 |
| 空白区域（KeepEmpty） | 大量 tile 涌入时产生高 cascade |

### Cascade 与体验

| 目标体验 | 平均 cascade/步 | 设计手段 |
|----------|---------------|---------|
| 爽快 | 1.5-2.0 | 高棋盘 + 4 色 + 多生成点 |
| 平衡 | 1.0-1.5 | 标准棋盘 + 5 色 |
| 策略 | 0.5-1.0 | 矮宽棋盘 + 6 色 + 瓶颈 |

---

## 5. Spawner 与填充

- 每列最顶部的非 Void 格自动作为 Spawner 点
- 每个可到达区域**必须有 Spawner**，否则消除后无法补充
- 用障碍堵住 Spawner 行会导致生成堵塞
- 生成内容由 Spawner 条件系统决定（详见 `spawner-mechanics.md`）

- [ ] 棋盘空白区域（KeepEmpty）在 dam break 时的 cascade 效果是否验证过？
