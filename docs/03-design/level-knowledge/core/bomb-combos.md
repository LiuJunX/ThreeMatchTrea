# 炸弹组合效果

做关前必读。当玩家**交换两个相邻的炸弹**时触发组合效果。

**重要**：链式反应中炸弹被波及时**不触发组合**——每个炸弹独立爆炸。组合只在玩家主动交换时发生。

---

## 组合效果速查表

| 组合 | 效果 | 清除范围（8×8 棋盘） |
|------|------|-------------------|
| **火箭 + 火箭** | 十字：1 整行 + 1 整列 | ~15 格 |
| **火箭 + 方炸弹** | 3 行 + 3 列 | ~39 格 |
| **火箭 + UFO** | 小十字 + 投射物（行/列载荷） | 5 + 远程行/列 |
| **火箭 + 彩球** | 全场某色 tile 变为火箭，逐个引爆 | 极大 |
| **方炸弹 + 方炸弹** | 9×9 区域 | ~64 格（几乎全场） |
| **方炸弹 + UFO** | 小十字 + 投射物（5×5 载荷） | 5 + 远程 5×5 |
| **方炸弹 + 彩球** | 全场某色 tile 变为方炸弹，逐个引爆 | 极大 |
| **UFO + UFO** | 双小十字 + 3 个投射物 | 10 + 3 个远程目标 |
| **UFO + 彩球** | 全场某色 tile 变为 UFO，逐个发射 | 极大 |
| **彩球 + 彩球** | **全场清除**（所有非空 tile） | 全场 |

## 详细说明

### 火箭 + 火箭

不论横纵，两个火箭交换后在交换位置释放十字爆炸：
```
. . X . .
. . X . .
X X ★ X X  ← 整行 + 整列
. . X . .
. . X . .
```

### 火箭 + 方炸弹

以方炸弹位置为中心，清除 3 行 + 3 列：
```
. X X X .
. X X X .
X X X X X  ← 中心行 ± 1
. X X X .
. X X X .
    ↑
  中心列 ± 1（整列清除）
```

### 方炸弹 + 方炸弹

以交换中心为原点，9×9 区域清除（半径 4）。在 8×8 棋盘上几乎是全场。

### 彩球 + 任意炸弹

彩球与非彩球炸弹交换时：
1. 确定目标颜色（由被交换 tile 的颜色或规则决定）
2. 全场该颜色的所有 tile **变形为对应炸弹类型**
3. 变形后的炸弹**逐个引爆**

例：彩球 + 横火箭 → 场上所有红色 tile 变为横火箭 → 全部引爆 → 清除大量行

### 彩球 + 彩球

**全场清除**——消除棋盘上所有非空、非 Void 的 tile。这是游戏中最强的组合。

### 火箭/方炸弹 + UFO

立即在 UFO 位置释放小十字（5 格），同时发射投射物：
- 火箭 + UFO：投射物携带**行或列载荷**（横火箭→行，纵火箭→列）
- 方炸弹 + UFO：投射物携带 **5×5 载荷**

### UFO + UFO

在两个 UFO 位置各释放一个小十字，同时发射 **3 个投射物**到 3 个不同远程目标。

## 关卡设计影响

| 设计意图 | 推荐组合机会 |
|----------|------------|
| 教学/简单关 | 不要求组合，自然 4 消即可 |
| 中等难度 | 提供火箭+火箭的组合空间 |
| 高难度 | 需要组合才能破局（如 Safe 区域周围留足制造空间） |
| 爽关/休息关 | 预置两个炸弹相邻，让玩家体验组合的视觉冲击 |

### 注意事项

- 彩球 + 彩球在前期关卡出现会让玩家困惑（全场清除太突然）
- 炸弹组合只在**玩家交换时触发**，AI 分析中 random 玩家不会主动制造组合
- 包含 Safe/Stone 的关卡，需确保火箭 + 方炸弹的组合空间存在
