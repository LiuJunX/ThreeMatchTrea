# Spawner 生成机制

做关前必读。新 tile 如何生成、生成什么、生成顺序由 Spawner 系统控制。

---

## 1. 生成时机

当棋盘顶部（每列最高的非 Void 格）为空时，Spawner 生成新 tile。新 tile 从顶部上方出现，带有初始下落速度。

---

## 2. 条件优先级系统

Spawner 使用**条件优先级**决定生成什么。条件按优先级从高到低依次检查，第一个满足的条件决定生成内容：

| 优先级 | 条件 | 作用 | 何时激活 |
|--------|------|------|---------|
| **600** | PresetQueue | 按预设序列生成固定 tile | 关卡配置了 preset 序列时 |
| **550** | PhasePreset | 阶段触发的预设序列 | 特定条件满足后（如某障碍全清） |
| **400** | ObjectiveDrop | 生成目标相关收集物（如 Bird） | 关卡有收集物目标时 |
| **100** | Default | 随机颜色生成 | **始终匹配**，作为兜底 |

**关键**：Default 条件永远匹配，保证每次生成都有结果。

---

## 3. Default 条件：随机颜色

大多数情况下，新 tile 由 Default 条件生成。它的行为：

### 颜色保底（硬阈值）

- 每种颜色有一个"连续未出现"计数器
- 当某颜色连续 **4 次未被生成**时，下一次**强制生成**该颜色
- 保证所有颜色持续出现，防止"颜色饥荒"

### 防连击

- 生成后检查：新 tile 是否和该列最顶部的 tile 颜色相同？
- 如果相同，重新随机（排除该颜色）
- 防止同列连续出现同色导致的视觉单调

### 帮助模式（Mercy）

当玩家处于困境时自动介入：
- **触发条件**：玩家失败 3+ 次 AND 剩余步数 ≤3 AND 目标进度 <90%
- **行为**：分析哪种颜色在生成位置能形成匹配，优先生成该颜色
- **原则**：只帮助，不增难

---

## 4. ObjectiveDrop 条件：收集物生成

当关卡目标需要收集特定元素（如 Bird）时自动激活。

### 生成概率

- 使用 **PRD（伪随机分布）**，不是均匀随机
- 基础概率 = `(目标数量 × 1.3) / 总步数`，上限 50%
- PRD 保证：不会连续太多步不出，也不会连续出太多

### 生成限制

| 限制 | 默认值 | 说明 |
|------|--------|------|
| 每步最多生成 | 1 个 | 防止一步掉太多收集物 |
| 场上同时最多 | 3 个 | 防止收集物堆积 |
| 总共最多生成 | 目标数 + 2 | 留一点余量 |

### 目标完成后

目标达成后，概率降为原来的 10%（不完全停止，允许偶尔出现）。

---

## 5. PresetQueue 条件：预设序列

由关卡设计者配置的固定生成序列。

- **优先级最高（600）**：会覆盖所有其他条件
- **按列独立跟踪**：每列有自己的序列进度
- **cycles**：
  - `1` = 序列播放一次就停止
  - `0` = 无限循环
  - `N` = 循环 N 次
- 序列耗尽后，降级到低优先级条件

### 用途

- 教学关：确保前几个 tile 是特定颜色
- 脚本关：在特定时机掉落炸弹
- 控制开局体验

---

## 6. PhasePreset 条件：阶段触发预设

PresetQueue 的条件触发变体。

- **优先级 550**
- **触发前**：`IsConditionMet` 返回 false，不干预生成
- **触发条件**：指定类型的障碍物在棋盘上全部清除（如所有 Box 被消灭）
- **触发后**：行为等同 PresetQueue，按预设序列生成

### 用途

- Dam Break：Box 全清后掉落一个炸弹
- 阶段转换：第一阶段障碍清完后引入新元素

---

## 7. 关卡设计影响

### 颜色数与生成

- 颜色少（3-4 色）→ 匹配频率高，cascade 多，体验爽快
- 颜色多（5-6 色）→ 匹配困难，需要更多步数
- 颜色保底（每 4 次强制）确保不会出现"某颜色一直不出"的问题

### 收集物关卡

- PRD 概率由系统自动计算，设计者只需设目标数量和步数
- 如果步数太少，概率会被压到上限 50%，仍可能不够——需要分析验证
- Bird 需要棋盘上有 Sink 格子才能生成

### Preset 使用建议

- 用于**强控体验**：教学、脚本、保证特定时刻的生成内容
- 不要滥用：过长的 Preset 会让生成变得可预测，失去随机性带来的新鲜感
- PhasePreset 适合做关卡内的"阶段切换"——前半段正常生成，后半段引入新元素
