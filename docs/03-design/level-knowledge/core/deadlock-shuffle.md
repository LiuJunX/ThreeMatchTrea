# 死锁检测与洗牌

做关前必读。棋盘无合法操作时的处理机制。

---

## 1. 什么是死锁

棋盘上**不存在任何合法操作**时为死锁状态。合法操作包括：
- 交换两个相邻 tile 后形成 3+ 匹配
- 交换任意 tile 与相邻炸弹（炸弹交换永远合法）
- 直接点击一个炸弹（不需要交换）

**场上有炸弹 = 不会死锁**（除非炸弹被 Cover 锁住无法操作）。

---

## 2. 检测时机

死锁检测在以下条件**全部满足**时运行：
1. 棋盘处于稳定状态（无 tile 在下落、无爆炸、无动画）
2. 上一轮有 match 被处理（cascade 结束后）
3. 未进入"洗牌失败"状态

**不检测的时机**：交换动画中、下落中、爆炸中、匹配检测中。

---

## 3. 洗牌行为

检测到死锁后自动触发洗牌：

### 洗什么

| 类型 | 是否被洗 |
|------|:-------:|
| 普通颜色 tile（Item1-Item6） | ✅ |
| 炸弹（火箭、方炸弹、UFO、彩球） | ❌ 保持不动 |
| 被 Cover 覆盖的 tile | ❌ 保持不动 |
| 障碍物 | ❌ 不受影响 |
| Cover / Ground 层 | ❌ 不受影响 |

### 怎么洗

1. 收集所有可洗的 tile 的颜色
2. Fisher-Yates 随机打乱颜色顺序
3. 把打乱后的颜色放回原位置
4. **Tile ID 不变**，只有颜色改变

### 保证有解吗？

**不保证。** 单次洗牌可能仍然无解。系统会**重复洗牌**直到有解：
- 最多尝试 **20 次**（可配置）
- 如果 20 次都无解 → 判定为**游戏失败**

### 目标进度

**不重置。** 洗牌只改变 tile 颜色分布，不影响已收集的目标进度。

---

## 4. 关卡设计影响

### 死锁高风险布局

| 布局特征 | 死锁风险 | 原因 |
|---------|---------|------|
| 颜色数少（3 色）+ 小棋盘 | 中 | 可能形成"棋盘式"无解排列 |
| 大面积 Cage/Honey 覆盖 | **高** | 减少可操作 tile，增加无解概率 |
| Cage 交错放置在中部 | **高** | 4 Cage 交错放中间 → 14.8% 死锁率 |
| 大面积障碍围堵 | 中 | 可操作区域过小 |
| 炸弹存在 | **低** | 炸弹可以被点击/交换，几乎不可能死锁 |

### 设计建议

- **分析管线检查死锁率**：>5% 需要调整布局
- **避免在瓶颈处堆叠 Cover**：减少可操作区域是死锁的主因
- **保证炸弹制造空间**：有炸弹在场几乎不死锁
- **Cage 放底部比中部安全**：底部不影响 tile 流动
- 洗牌是**兜底机制**，不应该被当作常规体验——频繁洗牌说明关卡设计有问题
