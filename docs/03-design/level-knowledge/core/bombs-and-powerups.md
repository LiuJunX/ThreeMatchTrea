# 炸弹与道具设计

## 道具生成条件

| 道具 | 触发条件 | 效果 |
|------|---------|------|
| 横向火箭 HorizontalRocket | 4 横消 | 清除整行 |
| 纵向火箭 VerticalRocket | 4 纵消 | 清除整列 |
| 炸弹 Square5x5 | T/L 形消 | 5×5 范围爆炸 |
| 彩虹球 ColorBomb | 5 连消 | 清除全场最多色 |
| UFO | 2×2 方形消 | 追踪目标元素 |

## 关卡设计价值

### 道具是解题工具

- **火箭**：清除整行/列，适合清远距离障碍、打通瓶颈
- **炸弹**：大范围清除，适合清密集障碍区
- **彩虹球**：全场清色，适合收集目标、触发大量连锁
- **UFO**：精准定向，适合清指定位置的障碍

### 道具依赖性设计

| 设计意图 | 做法 |
|----------|------|
| 道具是锦上添花 | 步数充裕，不靠道具也能过 |
| 道具是关键手段 | 必须保证棋盘可以制造对应道具 |
| 道具是必须条件 | **危险**——需确保 100% 可制造，否则有运气通关问题 |

**原则**：如果关卡 **必须** 靠道具通关，至少提供 2 条制造路径。

### 道具机会与难度

| 难度 | 道具机会 |
|------|---------|
| 简单 | 自然出现 4 消 |
| 普通 | 可以制造 T/L |
| 困难 | 5 消需要规划 |
| 挑战 | 需要组合道具（如火箭+彩虹球） |

## 与障碍的交互

- **Safe/Owl/Stone**：免疫普通匹配，**只能被炸弹/道具伤害**
  → 包含这些障碍的关卡必须保证道具可制造
- **Cage**：锁住方块不能交换 → 无法主动制造涉及被锁方块的道具
- **Honey**：粘住方块不能移动 → 不能用于制造 4 消

## 设计检查清单

- [ ] 包含 Safe/Stone/Owl 时，棋盘允许制造炸弹？
- [ ] 没有把所有 4 消机会都用障碍堵死？
- [ ] 如果目标依赖道具，至少有 2 条制造路径？
- [ ] 道具生成不会因颜色数过多而变得极不可能？
