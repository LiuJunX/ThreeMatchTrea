# 炸弹与道具机制

做关前必读。本文档覆盖炸弹的生成、触发、效果。组合效果见 `bomb-combos.md`。

---

## 1. 炸弹生成条件

| 炸弹 | 触发匹配 | 生成优先级(权重) |
|------|---------|-----------------|
| **UFO** | 2×2 方形匹配 **或** 十字形（3横+3竖交叉于中心） | 150（最高） |
| **彩球 ColorBomb** | 5 连消（横或竖） | 130 |
| **方炸弹 Square5x5** | T 形 / L 形匹配（总计 ≥5 格） | 60 |
| **纵火箭 VerticalRocket** | 4 横消 | 40 |
| **横火箭 HorizontalRocket** | 4 纵消 | 40 |

### 关键细节

- **火箭方向是反转的**：横向 4 连消生成**纵**火箭，纵向 4 连消生成**横**火箭。这让消除和爆炸方向交叉，制造更多连锁机会。
- **优先级决定生成**：当一次消除同时满足多种炸弹条件时（如 6 连消同时满足 ColorBomb 和 Rocket），系统选择权重最高的。
- **UFO 双来源**：2×2 方形和十字形都生成 UFO，但如果方形的行或列恰好构成 4 连消，则优先生成 Rocket。

## 2. 炸弹触发方式

| 触发方式 | 适用炸弹 | 说明 |
|---------|---------|------|
| **玩家点击** | 所有炸弹 | 直接点击炸弹 tile 即可激活 |
| **玩家交换** | 所有炸弹 | 与相邻 tile 交换即可激活（不需要形成匹配） |
| **被爆炸波及（链式激活）** | 火箭、方炸弹、UFO | 被其他炸弹的爆炸范围覆盖时自动引爆 |
| **被爆炸波及** | **彩球除外** ❌ | 彩球对爆炸波**免疫**，不会被链式激活 |
| **cascade（掉入匹配）** | 所有炸弹 | 炸弹掉落后参与了 3+ 匹配，作为匹配的一部分被处理 |

### 彩球的特殊性

彩球是唯一**不能被链式激活**的炸弹：
- `IsChainActivatable()` 对彩球返回 `false`
- 必须由玩家主动操作（点击或交换）才能激活
- 被爆炸波及时**不会爆炸**，只是被消除
- 设计意义：彩球是"策略工具"而非"连锁零件"，玩家必须主动决定何时使用

## 3. 炸弹效果

| 炸弹 | 效果范围 | 效果描述 |
|------|---------|---------|
| **横火箭** | 整行 | 清除炸弹所在行的所有 tile |
| **纵火箭** | 整列 | 清除炸弹所在列的所有 tile |
| **方炸弹** | 5×5 区域 | 以炸弹为中心，±2 格范围内全部清除（边缘裁剪） |
| **彩球（独立激活）** | 全场同色 | 清除场上数量最多的那种颜色的所有 tile |
| **彩球（交换激活）** | 全场指定色 | 清除与之交换的那个 tile 的颜色的所有同色 tile |
| **UFO（立即效果）** | 小十字（5格） | 中心 + 上下左右各 1 格 |
| **UFO（投射物）** | 远程单点 | 发射投射物追踪目标位置，到达后引爆 |

### UFO 双重效果

UFO 激活时同时产生两个效果：
1. **立即效果**：在 UFO 所在位置清除小十字（5 格）
2. **投射物效果**：发射投射物到远程目标（目标选择规则见 `ufo-mechanics.md`）

## 4. 链式反应规则

当一个炸弹爆炸时，爆炸范围内的**其他炸弹**（彩球除外）会被链式激活：

```
玩家激活方炸弹 A
→ A 爆炸（5×5 范围）
→ 范围内有一个纵火箭 B
→ B 被链式激活，爆炸（整列）
→ B 的爆炸范围内有横火箭 C
→ C 被链式激活，爆炸（整行）
→ ...直到没有更多炸弹被波及
```

关键规则：
- **发起爆炸的炸弹本身不会被自己的爆炸再次触发**
- **链式激活不触发炸弹组合**——每个炸弹独立爆炸，不执行组合效果
- **彩球免疫**——被爆炸波及时不爆炸，只是被消除

## 5. 关卡设计影响

### 道具依赖性设计

| 设计意图 | 做法 |
|----------|------|
| 道具锦上添花 | 步数充裕，不靠道具也能过 |
| 道具是关键手段 | 必须保证棋盘可以制造对应道具 |
| 道具是必须条件 | **危险**——需确保 100% 可制造，否则有运气通关问题 |

### 与障碍的交互

- **Safe/Owl/Stone**：免疫普通匹配，**只能被炸弹伤害** → 关卡必须保证道具可制造
- **Cage**：锁住方块不能交换 → 被锁的炸弹无法被玩家点击或交换激活，但仍可被链式激活
- **Honey**：粘住方块不能移动 → 不能用于制造 4 消

### 设计检查清单

- [ ] 包含 Safe/Stone/Owl 时，棋盘允许制造炸弹？
- [ ] 没有把所有 4 消机会都用障碍堵死？
- [ ] 如果目标依赖道具，至少有 2 条制造路径？
- [ ] 道具生成不会因颜色数过多而变得极不可能？
- [ ] 彩球只能玩家主动激活——关卡设计不能依赖彩球被链式触发
