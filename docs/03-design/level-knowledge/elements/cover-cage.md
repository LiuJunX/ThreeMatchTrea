# Cage 笼子 — 关卡设计指南

## 关卡设计价值

Cage 锁住方块，阻止匹配、交换和移动。它是最直接的"减法"元素——减少可操作区域：
- **限制操作**：被锁方块无法交换或匹配
- **资源保护/阻碍**：锁住的方块位置固定，可用于"保护"也可用于"阻碍"
- **创造紧迫感**：玩家需要"解锁"才能访问某些区域

## 属性速查

| 属性 | 值 |
|------|-----|
| 层级 | Cover（覆盖在 Tile 上方） |
| 默认 HP | 1 |
| 阻止匹配 | ✓ |
| 阻止交换 | ✓ |
| 阻止移动 | ✓ |
| 消除方式 | 被炸弹波及消除 |

## 放置原则

### 宜

- **保护特定方块**：锁住一个关键位置的特殊方块
- **边缘/半外围**：让玩家需要用炸弹"开锁"，但不阻挡核心匹配区
- **少量散布**：5-8 个分散放置，每个 Cage 是一个小任务
- **配合 Ice**：Cage 在 Ice 上方 → 需要先清 Cage 再清 Ice，层次感

### 忌

- **密集成片**：大面积 Cage 导致完全无法操作
- **所有 Spawner 列都有 Cage**：新生成的方块立刻被锁，没有操作空间
- **与 Honey 叠加**：两者都限制操作，叠加 = 死区

### 注意

- Cage 只能放在有 Tile 的格子上（不能放在 Obstacle 格子上）
- Cage 内的方块不会掉落 → Cage 下方可能形成空隙

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Ice | 好：双层挑战，先解锁再破冰 | ★★★ |
| Box | 搭配：Cage 限制操作区域，Box 消耗步数 | ★★☆ |
| Chain | 冗余：两者功能类似（都限制交换），不推荐同时大量使用 | ★☆☆ |
| Moving obstacles | 有趣：锁住移动障碍阻止其掉落 | ★★☆ |

## 目标设计

- **"清除 N 个 Cage"** 作为目标时，target = 实际放置数
- 注意：Cage 只有 1HP，消除不难但需要**触及**（炸弹波及）
- 分散放置的 Cage 比密集的更难完成目标（需要多个炸弹）

## 常见设计错误

1. **Cage 包围整个区域** → 没有起始操作点
2. **首次引入就大面积** → 玩家不理解解锁方法就被困住
3. **与 Honey 双重封锁** → 体验极差
4. **忘记 Cage 不能放在 Obstacle 上** → 配置无效
