# Frost 冰霜 — 关卡设计指南

## 关卡设计价值

Frost 冻结方块在原地——允许匹配但阻止交换和移动：
- **固定锚点**：类似 Chain，但被相邻消除也能破坏
- **温和限制**：匹配仍然有效
- **易碎**：1HP + 相邻消除或直接命中都能破坏

## 属性速查

| 属性 | 值 |
|------|-----|
| HP | 1 |
| 阻止匹配 | ✗（允许匹配） |
| 阻止交换 | ✓ |
| 阻止移动 | ✓ |
| 消除方式 | 直接命中或相邻消除 |
| 动态 | ✗（静态） |

## 放置原则

### 宜

- **中等密度散布**：每个 Frost 影响小，可以多放
- **配合掉落设计**：Frost 阻止掉落，影响连锁流
- **作为"减速带"**：让某些区域的方块暂时固定
- **与 Ice 搭配**：两者都是"冰"主题，但层级不同

### 忌

- **过度密集**：大面积 Frost 停止掉落 = 无连锁
- **与 Chain 功能重复**：两者效果非常相似

### 与 Chain 的区别

- **Chain**：只能通过包含方块被消除来破坏
- **Frost**：可以被相邻消除破坏（更容易清除）

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Ice（Ground 层） | 好：冰主题统一，双层"冰"挑战 | ★★★ |
| Box | 好：混合限制 | ★★☆ |
| Honey | 注意：两者都限制移动 | ★☆☆ |

## 常见设计错误

1. **Frost + Chain 同关大量使用** → 功能几乎相同，无差异感
2. **密集 Frost 停滞整个区域** → 无掉落无连锁
3. **忘记相邻消除能破 Frost** → 实际比预期更容易清除
