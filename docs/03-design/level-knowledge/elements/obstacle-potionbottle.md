# PotionBottle 药水瓶 — 关卡设计指南

## 关卡设计价值

PotionBottle 是独特的"多色子瓶"障碍——4 个子瓶各对应一种颜色，需要分别击破：
- **颜色规划**：需要消除红、绿、蓝、黄四种颜色才能彻底摧毁
- **随机顺序**：子瓶可以任意顺序击破
- **视觉丰富**：4 个子瓶逐个破碎，有节奏感

## 属性速查

| 属性 | 值 |
|------|-----|
| HP | 4（popcount of state bitmask） |
| State | 位掩码：bit0=红, bit1=绿, bit2=蓝, bit3=黄（默认 0x0F） |
| 消除方式 | 匹配对应颜色（清除对应 bit）或 炸弹/道具（清除最低位子瓶） |
| 免疫 | 普通匹配免疫；颜色匹配和道具有效 |
| 死亡效果 | 无 |

## 放置原则

### 宜

- **场上有全部 4 种颜色流通**：红绿蓝黄都需要
- **颜色数 4-5 色**：目标色出现概率合理
- **中央位置**：方块流通量大，各色均可达
- **1-2 个足矣**：每个需要 4 次不同色命中

### 忌

- **6-7 色关卡**：每种色出现概率低，4 色全覆盖难
- **边角**：色彩流通差
- **>3 个**：4×3=12 次色彩命中需求，极高
- **旁边有 Honey/Cage**：限制操作妨碍配色

### 关键设计规则

PotionBottle 需要场上流通**至少 4 种颜色**（Item1-Item4）。如果颜色数 = 3，理论上不可能清除。

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| ColorBox | 有趣：两者都需要颜色策略 | ★★★ |
| Box（普通） | 好：Box 消耗步数，PotionBottle 消耗颜色策略 | ★★☆ |
| Safe | 注意：PotionBottle 已经很难了 | ★☆☆ |

## 常见设计错误

1. **颜色数 < 4** → 某种子瓶永远无法击破
2. **PotionBottle 被隔离** → 各色方块到不了
3. **忘记炸弹清除最低位** → 炸弹可以绕过颜色限制（降低实际难度）
4. **与"收集色块"目标冲突** → 收集和击破争夺同种颜色
