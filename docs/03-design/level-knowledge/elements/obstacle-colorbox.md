# ColorBox 彩色箱 — 关卡设计指南

## 关卡设计价值

ColorBox 是"只能用对应颜色消除"的障碍——引入**颜色规划**维度：
- **颜色策略**：玩家必须在特定位置消除特定颜色
- **冲突制造**：如果收集目标也要红色，ColorBox(红)就和目标争夺资源
- **多样性**：同一关可放不同颜色的 ColorBox，增加策略层

## 属性速查

| 属性 | 值 |
|------|-----|
| 最大 HP | 3 |
| State | 存储颜色变体（ElementType 1-6） |
| 消除方式 | 匹配对应颜色（相邻）或 炸弹/道具直接命中 |
| 免疫匹配 | 部分（仅对应颜色有效） |
| 死亡效果 | 无 |

## 放置原则

### 宜

- **颜色可控区域**：确保 ColorBox 旁有足够的颜色种类流通
- **颜色数 ≤5 时使用**：颜色数越少，目标色出现频率越高，越容易清除
- **2-3 种颜色的 ColorBox 混合**：制造有趣的优先级选择
- **靠近中央**：方块流通量大，更容易匹配到需要的颜色

### 忌

- **7 色 + ColorBox**：目标色出现概率 ≈14%，极难清除
- **角落放置**：流通量小 + 颜色要求 = 极端困难
- **同色 ColorBox 大量集中**：需要大量同色方块，步数消耗巨大
- **与收集同色方块目标冲突**：除非有意设计冲突目标

### 颜色选择建议

- 选棋盘上**流通量最大的列**对应的颜色
- 不同 ColorBox 用不同颜色，避免颜色饥荒
- 彩虹球可以无视颜色限制清除 ColorBox

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Box | 好：Box 无色限制 + ColorBox 有色限制，层次分明 | ★★★ |
| Curtain（同色） | 有趣：全局色消除 + ColorBox 色消除，策略联动 | ★★☆ |
| Safe | 注意：都是高门槛障碍，对玩家压力大 | ★☆☆ |

## 常见设计错误

1. **ColorBox 颜色 = Spawner 不生成的颜色** → 无法清除
2. **全部同色** → 颜色饥荒，步数极度不足
3. **忘记炸弹可以绕过颜色限制** → 实际难度比预期低
4. **与"收集红色 ×30"搭配红色 ColorBox** → 颜色争夺太激烈
