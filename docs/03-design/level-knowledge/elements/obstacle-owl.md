# Owl 猫头鹰石像 — 关卡设计指南

## 关卡设计价值

Owl 是 1HP 的"只能用道具打"障碍——最轻量的道具门槛元素：
- **道具入门**：比 Safe/Stone 更简单（1 hit），适合首次引入道具需求
- **精准消耗**：每个 Owl 需要恰好 1 次道具命中
- **散布阻挡**：可散布多个，每个都是小型道具任务

## 属性速查

| 属性 | 值 |
|------|-----|
| HP | 1 |
| 消除方式 | 仅炸弹/道具 |
| 免疫匹配 | ✓ |
| 死亡效果 | 无 |

## 放置原则

### 宜

- **散布在关键位置**：阻挡路径，每个需要一次道具清除
- **与可匹配消除的障碍混合**：Owl + Box 组合，一个需要道具一个不需要
- **保证 4 消空间**：附近必须能制造火箭

### 忌

- **大量集中**：多个 Owl 需要多次道具，消耗太大
- **没有 4 消空间**：无法制造道具 = 无法清除
- **与 Safe/Stone 混用过多**：全是道具需求，压力巨大

## 与 Safe/Stone 对比

| 属性 | Owl | Safe | Stone |
|------|-----|------|-------|
| HP | 1 | 最高 5 | 最高 3 |
| 道具消耗 | 1 次 | 多次 | 多次 |
| 适合阶段 | 首次引入 | 中期 | 后期 |

## 常见设计错误

1. **>8 个 Owl** → 需要太多道具命中
2. **Owl 在 6-7 色关卡中** → 道具制造困难
3. **紧邻另一个道具专属障碍** → 局部道具需求爆炸
