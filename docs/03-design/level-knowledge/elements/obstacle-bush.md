# Bush 灌木 — 关卡设计指南

## 关卡设计价值

Bush 是"清除后有奖励"的障碍物——死亡时在四周生成 Grass，创造连锁反应式的关卡设计：
- **空间争夺**：占格子阻挡掉落，清除后释放空间
- **目标生产**：死亡生成 Grass，可作为 Ground 目标的来源
- **战术层次**：先打 Bush → 生成 Grass → 再清 Grass，多步规划

## 属性速查

| 属性 | 值 |
|------|-----|
| 最大 HP | 5 |
| 消除方式 | 任何消除源（匹配、炸弹、连锁） |
| 免疫匹配 | 否 |
| 死亡效果 | 四方向相邻格生成 Grass（十字形：上下左右） |

## 放置原则

### 宜

- **周围有空位**：死亡效果需要四周有空格（有 Tile 的 Slot）才能铺 Grass
- **中央偏位**：四周都有格子，Grass 生成效率最高
- **配合 Grass 目标**："清 N 个 Grass"目标 + 足够 Bush = 自然的生产链
- **分散放置**：每个 Bush 独立产出 Grass，分散比集中更好

### 忌

- **边角放置**：只有 1-2 个相邻格，Grass 产出少
- **紧邻 Void/Wall**：死亡效果浪费
- **紧邻其他 Obstacle**：Obstacle 格无法生成 Grass
- **密集成片**：互相挤占死亡效果空间

### HP 使用

- 低 HP(1-2)：快速清除，适合 Grass 生产目的
- 高 HP(4-5)：本身就是挑战目标，Grass 是附带奖励

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Grass 目标 | 核心组合：Bush 产 Grass，目标清 Grass | ★★★ |
| Ice | 可以：Bush 旁有 Ice，清 Bush 后铺 Grass 覆盖 Ice 位 | ★★☆ |
| Box | 好：Box + Bush 混合防线 | ★★☆ |
| Flowerpot | 注意：两者都产 Grass，可能过度生产 | ★☆☆ |

## 常见设计错误

1. **Grass 目标数 > Bush 能产出的 Grass 总数** → 不可完成
2. **Bush 四周全是障碍** → 死亡效果完全浪费
3. **首次引入就 5HP** → 玩家不理解死亡效果
4. **忘记 Grass 有 0.4s 生成保护** → 不影响设计，但动画需要时间
