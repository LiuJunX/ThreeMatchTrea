# Mailbox 邮箱 — 关卡设计指南

## 关卡设计价值

Mailbox 是永久生成器——每次相邻消除或炸弹命中都在旁边空格生成 Envelope：
- **持续产出**：不可摧毁，每次相邻消除都生成
- **高效率**：比 MagicHat(需要 3 次) 更频繁产出
- **空间竞争**：产出的 Envelope 占用相邻空格

## 属性速查

| 属性 | 值 |
|------|-----|
| HP | 不可摧毁（永久生成器） |
| 触发 | 相邻格消除（任何源）或 炸弹命中 |
| 产出 | Envelope（收集物，生成在相邻空格） |
| 频率 | 每次触发生成 1 个（无累积阈值） |

## 放置原则

### 宜

- **中央偏位**：相邻格多，触发频率高
- **配合 Envelope 收集目标**：唯一产出源
- **1-2 个足矣**：每次相邻消除就产出，效率极高
- **留足相邻空格**：产出需要空位

### 忌

- **没有 Envelope 目标**：产出物无意义且占空间
- **被障碍包围**：无空格产出
- **数量过多**：Envelope 泛滥，阻碍正常匹配
- **Spawner 行**：占格子影响生成

## 与 MagicHat 对比

| 属性 | MagicHat | Mailbox |
|------|----------|---------|
| 触发阈值 | 3 次 | 1 次（每次都触发） |
| 产出 | Diamond | Envelope |
| 效率 | 低（慢但稳定） | 高（快但可能过多） |

## 常见设计错误

1. **Envelope 目标太少 + Mailbox 产出太多** → 目标秒完，无挑战
2. **Mailbox 周围无空格** → 产出被浪费
3. **多个 Mailbox 紧邻** → Envelope 泛滥堵塞棋盘
