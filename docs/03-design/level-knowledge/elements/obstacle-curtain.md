# Curtain 幕帘 — 关卡设计指南

## 关卡设计价值

Curtain 通过**全局色消除**机制触发——消除全场某种颜色时，对应颜色的 Curtain 被破坏：
- **全局视野**：玩家需要关注全场而非局部
- **彩虹球联动**：ColorBomb 可以一次触发大量 Curtain
- **颜色规划**：选择消除哪种颜色影响全局

## 属性速查

| 属性 | 值 |
|------|-----|
| HP | 1 |
| State | 存储颜色变体（ElementType 1-6） |
| 消除方式 | 全局色消除事件（非直接命中、非相邻） |
| 免疫 | 直接命中和相邻消除均无效 |
| 死亡效果 | 无 |

## 放置原则

### 宜

- **分散在全场**：Curtain 的触发是全局的，位置不影响触发条件
- **多种颜色混合**：不同颜色 Curtain 需要消除不同颜色，增加策略层
- **与彩虹球机会搭配**：保证玩家可以制造 5 消
- **颜色数 ≤5**：每种颜色出现频率高，全局消除更容易触发

### 忌

- **7 色**：目标色占比低，全局消除极难
- **同色太多**：需要反复触发同色消除
- **期望炸弹清 Curtain**：直接命中无效！只有全局色消除才行
- **角落密集**：虽然触发是全局的，但 Curtain 占格子影响局部流动

### 全局色消除条件

Curtain 在以下情况被触发：
- 玩家消除了与 Curtain 颜色匹配的方块群
- **ColorBomb 是最有效的触发手段**（一次消除一种颜色的所有方块）

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| ColorBox（同色） | 有趣：消除目标色同时破 Curtain | ★★★ |
| 收集色块目标 | 好：收集过程自然触发 Curtain | ★★☆ |
| Safe | 注意：两者都有特殊消除条件 | ★☆☆ |

## 常见设计错误

1. **以为炸弹能清 Curtain** → 不行，只有全局色消除
2. **Curtain 颜色 = 场上稀缺色** → 几乎无法触发
3. **首次引入不解释机制** → 玩家困惑为什么打不掉
4. **目标"清除 Curtain" + 没有彩虹球空间** → 极难完成
