# MagicHat 魔法帽 — 关卡设计指南

## 关卡设计价值

MagicHat 是永久生成器——累积 3 次相邻消除后产出 Diamond：
- **持续产出**：不会被摧毁，持续为玩家生产收集物
- **位置博弈**：玩家需要在 MagicHat 旁边反复消除
- **长线规划**：每 3 次触发产出一个，需要规划步数分配

## 属性速查

| 属性 | 值 |
|------|-----|
| HP | 不可摧毁（永久生成器） |
| State | 累积计数器（0→1→2→3→重置） |
| 触发 | 相邻格消除（任何消除源） |
| 产出 | Diamond（收集物，生成在相邻空格） |
| 阈值 | 3 次相邻消除触发一次 |

## 放置原则

### 宜

- **中央位置**：四面八方都有消除机会，触发效率高
- **远离边角**：边角触发机会少（只有 2 个相邻格）
- **数量克制**：1-2 个足以，每个都是持续产出源
- **配合 Diamond 收集目标**：有 MagicHat 才可能有 Diamond 目标

### 忌

- **Spawner 行**：占格子影响生成
- **被障碍包围**：相邻格全是障碍 = 无法触发
- **数量过多**：3+ 个 MagicHat 产出太多 Diamond，目标太容易
- **没有 Diamond 目标时放 MagicHat**：产出物无意义

### 触发效率

- 4 个相邻格可操作 → 每 3-4 步触发一次
- 2 个相邻格可操作 → 每 6-8 步触发一次
- **目标 Diamond 数 × 3 ≈ 需要的相邻消除次数**

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Diamond 收集目标 | 必须：MagicHat 的存在意义 | ★★★ |
| Box（相邻） | 好：清 Box 顺便触发 MagicHat | ★★★ |
| Honey（相邻） | 差：Honey 阻止旁边操作，降低触发率 | ✗ |

## 常见设计错误

1. **没有 Diamond 目标** → MagicHat 纯粹浪费格子
2. **Diamond 目标数太大** → 需要大量触发次数，步数不足
3. **MagicHat 被完全包围** → 无法触发
4. **产出 Diamond 无空格落脚** → 静默跳过，浪费触发
