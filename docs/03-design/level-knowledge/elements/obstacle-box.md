# Box 障碍物 — 关卡设计指南

## 关卡设计价值

Box 是最基础的障碍物——占据格子、阻挡掉落、需要被消除。它的价值在于：
- **空间控制**：限制可用匹配区域
- **资源消耗**：每层 HP 消耗玩家步数
- **节奏调节**：低 HP Box 是热身，高 HP Box 是挑战

## 属性速查

| 属性 | 值 |
|------|-----|
| 最大 HP | 4 |
| 消除方式 | 任何消除源（匹配、炸弹、连锁） |
| 免疫匹配 | 否 |
| 死亡效果 | 无 |

## 放置原则

### 宜

- **中央区域**：玩家容易接触，不会造成死角
- **成组放置**：3-5 个 Box 形成一个"任务区"，有节奏感
- **作为分隔线**：一排 Box 把棋盘分成上下两区
- **保护目标**：Box 后面藏着玩家需要收集的方块

### 忌

- **Spawner 行**：堵住生成点，导致生成堵塞
- **瓶颈处**：在狭窄通道放 Box 极易造成死局
- **全部最高 HP**：太 frustrating，应该混合 1-2 层和 3-4 层
- **角落堆叠**：角落本身就难清除，高 HP Box 在角落 = 纯运气

### HP 分配建议

| 阶段 | 推荐 HP | 说明 |
|------|---------|------|
| 首次引入（31-40关） | 1-2 | 让玩家理解机制 |
| 常规使用（41-80关） | 1-3 | 混合分配 |
| 后期挑战（81+关） | 2-4 | 核心区高 HP，边缘低 HP |

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Ice（地面层） | 双层挑战：先清 Ice 再清 Box | ★★★ |
| Cage（覆盖层） | 不搭配——Box 占格子没有 tile，无法放 Cage | ✗ |
| 其他 Box | 围墙模式：Box 围成一圈保护中央 | ★★★ |
| Safe | 混合防线：Box 可匹配消、Safe 需炸弹 | ★★☆ |

## 目标设计

- **"清除 N 个 Box"** 是最直观的障碍目标
- target = 实际放置数量（不要让玩家猜还有几个没清）
- 建议搭配一个收集色块目标，制造"先清障碍、后收集"的节奏

## 常见设计错误

1. **全高 HP + 角落放置** → 纯运气，玩家无法规划
2. **数量太多占满棋盘** → 没有匹配空间，死局
3. **对称放置太规整** → 无聊，缺乏策略选择
4. **首次引入就 4 HP** → 玩家不理解机制就被难到
