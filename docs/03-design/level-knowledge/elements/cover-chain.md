# Chain 锁链 — 关卡设计指南

## 关卡设计价值

Chain 阻止交换和移动，但**允许匹配**——比 Cage 更温和的限制：
- **半限制**：被锁方块可以参与匹配但不能被交换或掉落
- **固定位置**：方块钉在原地，改变掉落流
- **与 Cage 差异化**：Cage 完全封锁，Chain 保留匹配能力

## 属性速查

| 属性 | 值 |
|------|-----|
| HP | 1 |
| 阻止匹配 | ✗（允许匹配） |
| 阻止交换 | ✓ |
| 阻止移动 | ✓ |
| 消除方式 | 包含的方块被消除时（匹配或炸弹） |

## 放置原则

### 宜

- **在容易形成匹配的位置**：Chain 内方块可以被匹配消除
- **创造"固定锚点"**：Chain 内方块不掉落，成为稳定匹配目标
- **与色块收集目标搭配**：Chain 内方块可以被匹配收集
- **散布使用**：每个 Chain 是一个小谜题

### 忌

- **与 Cage 混淆使用**：两者功能相似，同关大量混用令人困惑
- **Chain 在孤立位置**：无法与周围方块匹配 → 只能用炸弹清
- **密集成片**：大面积 Chain 导致掉落完全停滞

### 与 Cage 的关键区别

| | Cage | Chain |
|---|------|-------|
| 匹配 | 阻止 | 允许 |
| 难度 | 高（只能炸弹） | 中（匹配即可） |
| 适合引入 | 更早（11-30 关） | 稍后（31-55 关） |

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Ice | 好：Chain 固定方块，匹配消除同时破 Ice | ★★★ |
| Box | 好：Box 阻挡 + Chain 限制操作 | ★★☆ |
| Cage | 不推荐同关大量使用：功能重叠 | ★☆☆ |

## 常见设计错误

1. **Chain 包含的方块颜色与周围不匹配** → 无法通过匹配消除
2. **密集 Chain 阵列** → 掉落完全停止，新方块无法补充
3. **与 Cage 同时大量使用** → 玩家分不清区别
