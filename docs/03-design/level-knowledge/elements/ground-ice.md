# Ice 冰层 — 关卡设计指南

## 关卡设计价值

Ice 是最基础的 Ground 层元素——在 Tile 下方，消除上方 Tile 时被击破：
- **低门槛挑战**：消除任何方块都能破冰，入门友好
- **区域标记**：冰块区域视觉清晰，引导玩家关注
- **自然协同**：收集色块目标和清冰目标可以同时完成

## 属性速查

| 属性 | 值 |
|------|-----|
| 层级 | Ground（Tile 下方） |
| 默认 HP | 1（蓝图中可配最高 3） |
| 消除方式 | 上方 Tile 被消除时扣 1 HP |
| 死亡效果 | 无 |

## 放置原则

### 宜

- **成片放置**：如中央 3×3、边缘一圈 → 形成清晰的"冰块区"
- **几何图案**：菱形、十字形的冰块区有视觉引导作用
- **与收集目标协同**："收集 20 红色 + 清除 15 冰块"，玩家在收集红色的过程中自然破冰
- **渐进 HP**：外围 1HP、内部 2-3HP → 由外向内层层剥离

### 忌

- **边角零散 1-2 个**：既不构成挑战也没视觉效果
- **全部最高 HP + 覆盖整个棋盘**：变成纯消耗战，无趣
- **与 Obstacle 放在同一格**：Obstacle 占格子，没有 Tile → 没法破冰

### HP 分配建议

| 场景 | HP | 说明 |
|------|-----|------|
| 教学 / 首次引入 | 1 | 消一下就碎 |
| 标准使用 | 1-2 | 外薄内厚 |
| 高难度 | 2-3 | 需要多次消除同一位置 |

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Cage | 好：先解 Cage 再破冰，双层挑战 | ★★★ |
| Box（相邻） | 好：Box 旁边的冰需要先清 Box 才能接触 | ★★☆ |
| Honey | 可以：Honey 锁住上方方块，无法直接破冰 | ★★☆ |
| 其他 Ground（Grass/Leaves） | 不能：同一格只有一个 Ground | ✗ |

## 目标设计

- **"清除 N 块冰"** 是最自然的 Ground 目标
- target = 实际放置数量
- 与色块收集目标天然协同：消除方块既收集又破冰
- 多层冰只算最终破碎时的 1 次

## 常见设计错误

1. **冰块下放 Obstacle** → Ground 和 Obstacle 在同一格无意义
2. **全场冰覆盖 + 3 层 HP** → 纯粹消耗步数，无策略
3. **冰块放在 Void 旁边** → Void 旁方块不易被消除
4. **目标数 > 放置数** → 永远无法完成
