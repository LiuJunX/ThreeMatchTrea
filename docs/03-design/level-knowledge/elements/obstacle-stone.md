# Stone 石块 — 关卡设计指南

## 关卡设计价值

Stone 是高 HP 的"只能用道具打"障碍——3 阶段，需要反复炸弹命中：
- **步数黑洞**：每层需要 1 次道具命中，3 层 = 3 次道具
- **区域封锁**：不可穿透，分隔棋盘区域
- **后期核心挑战**：与 Safe 并列为最难的静态障碍

## 属性速查

| 属性 | 值 |
|------|-----|
| 最大 HP | 3 |
| 消除方式 | 仅炸弹/道具 |
| 免疫匹配 | ✓ |
| 死亡效果 | 无 |

## 放置原则

### 宜

- **作为"墙壁"分隔区域**：Stone 行/列分割棋盘
- **少量(2-4 个)**：每个都是重投入
- **靠近宽阔区域**：保证附近可制造道具
- **混合 HP**：外围 1-2HP，核心 3HP

### 忌

- **与 Safe 大量混用**：都需要道具，需求叠加
- **角落 3HP**：几乎不可能清除
- **>6 个**：道具需求不现实
- **6-7 色关卡**：道具制造概率太低

## 与 Safe 的区别

两者都是道具专属，设计上的差异：
- **Safe**：最高 5HP，更适合单一大型障碍
- **Stone**：最高 3HP，更适合"石墙"阵列

## 常见设计错误

1. **Stone 墙完全封锁** → 没有绕行路径，必须全清才能过
2. **Stone + Safe + Owl 同关** → 道具需求灾难
3. **目标"清除 Stone" + 步数不足** → 无法制造足够道具
