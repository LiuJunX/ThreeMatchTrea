# 移动障碍物 — 关卡设计指南

移动障碍物（Moving Obstacles）位于 Tile 层，受重力影响掉落，类似可收集物但需要消除。

## 共同特征

- 位于 **Grid/Tile 层**（不是 Obstacle 层）
- 受重力影响正常掉落
- 不可交换
- 不参与匹配（不能被"滑动"操作）
- 需要被消除（炸弹波及、相邻匹配等）

---

## RoyalEgg 皇家蛋

| 属性 | 值 |
|------|-----|
| HP | 1 |
| 消除方式 | 任何消除源 |
| 死亡效果 | 无 |

**设计价值**：最简单的移动障碍，占据格子阻碍匹配，1 hit 清除。

**放置建议**：
- 适合首次引入移动障碍概念
- 少量散布（3-5 个）
- 会掉落到底部，注意底部空间

---

## Vase 花瓶

| 属性 | 值 |
|------|-----|
| HP | 2 |
| 消除方式 | 任何消除源 |
| 死亡效果 | 无 |

**设计价值**：2 hit 移动障碍，比 RoyalEgg 更耐久。

**放置建议**：
- 需要多次命中，更消耗步数
- 掉落过程中可能躲开炸弹范围
- 搭配火箭效果好（整行/列清除）

---

## PorcelainPiggy 瓷猪

| 属性 | 值 |
|------|-----|
| HP | 1 |
| 消除方式 | **仅炸弹/道具**（免疫普通匹配） |
| 死亡效果 | 无 |

**设计价值**：移动版的 Owl——必须用道具命中，且会掉落移位。

**放置建议**：
- 后期元素，需要玩家精准使用道具
- 会掉落 → 炸弹需要预判落点
- 保证附近有 4 消空间
- **与 Safe/Owl 同理**：需要道具，注意道具制造空间

**注意**：因为会移动，比静态的 Owl 更难命中。

---

## Oyster 牡蛎

| 属性 | 值 |
|------|-----|
| HP | 3 |
| 消除方式 | 任何消除源 |
| 死亡效果 | 在原位释放 Pearl 收集物 |

**设计价值**：高 HP 移动障碍 + 死亡释放 Pearl，是移动版的 Cupboard。

**放置建议**：
- **Pearl 收集目标的唯一来源**
- 3HP 需要多次命中，且 Oyster 会掉落移位
- 数量 = Pearl 目标数
- 释放的 Pearl 在 Oyster 死亡位（可能已掉落到底部）

**常见错误**：Pearl 目标 > Oyster 数量 → 不可完成

---

## Flowerpot 花盆

| 属性 | 值 |
|------|-----|
| HP | 2 |
| 消除方式 | 任何消除源 |
| 死亡效果 | 在 3×3 区域铺设 Grass（最多 9 格） |

**设计价值**：移动的 Grass 生产工厂——掉落到哪就在哪产 Grass。

**放置建议**：
- **Leaves/Grass 目标的重要来源**
- 2HP，会掉落后再死亡 → Grass 铺设位置不可预判
- 产出面积大（3×3），比 Bush（十字 4 格）更广
- 确保死亡位置附近有空格可铺 Grass

**常见错误**：Flowerpot 落入角落 → 3×3 区域大部分是 Void → Grass 产出不足

---

## 通用设计原则

1. **移动 = 不可预判**：移动障碍会掉落，所以它们的最终位置和效果取决于消除顺序
2. **数量控制**：移动障碍占格子 + 掉落 + 不可匹配 = 对棋盘干扰大，3-5 个为宜
3. **底部堆积**：如果不及时清除，移动障碍会沉到底部堆积
4. **道具专属型（PorcelainPiggy）更难**：需要精准预判位置 + 道具命中

## 组合建议

| 组合 | 效果 | 推荐度 |
|------|------|--------|
| Oyster + Pearl 目标 | 核心组合 | ★★★ |
| Flowerpot + Grass/Leaves 目标 | 核心组合 | ★★★ |
| RoyalEgg + Cage | 有趣：Cage 锁住 RoyalEgg 阻止掉落 | ★★☆ |
| PorcelainPiggy + Safe | 危险：双重道具需求 | ★☆☆ |
