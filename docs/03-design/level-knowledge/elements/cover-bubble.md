# Bubble 气泡 — 关卡设计指南

## 关卡设计价值

Bubble 是唯一的**动态 Cover**——跟随方块掉落移动，阻止交换但允许匹配：
- **移动谜题**：气泡方块会掉落到新位置，增加不确定性
- **温和限制**：只阻止交换，不阻止匹配和掉落
- **动态变化**：随着消除推进，气泡方块的位置会改变

## 属性速查

| 属性 | 值 |
|------|-----|
| HP | 1 |
| 阻止匹配 | ✗（允许匹配） |
| 阻止交换 | ✓ |
| 阻止移动 | ✗（跟随方块掉落） |
| 动态 | ✓（唯一的动态 Cover） |
| 消除方式 | 包含的方块被消除时 |

## 放置原则

### 宜

- **上半部分**：气泡会跟随方块掉落，放上面有更多移动空间
- **散布使用**：每个气泡是一个移动的小障碍
- **与匹配友好**：因为允许匹配，只要颜色对上就能消除
- **增加变数**：气泡方块掉落后位置改变，制造动态挑战

### 忌

- **底部固定位置**：气泡在底部无法展示其动态特性
- **大面积使用**：大量气泡方块都不能交换 → 操作受限严重
- **与 Chain/Cage 混合过多**：三种限制交换的 Cover 同时出现太混乱

### 与其他 Cover 对比

| Cover | 匹配 | 交换 | 移动 | 动态 |
|-------|------|------|------|------|
| Cage | ✗ | ✗ | ✗ | ✗ |
| Chain | ✓ | ✗ | ✗ | ✗ |
| Bubble | ✓ | ✗ | ✓ | ✓ |
| Honey | ✗ | ✗ | ✗ | ✗ |
| Frost | ✓ | ✗ | ✗ | ✗ |

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Ice | 好：气泡方块掉落后可能落在 Ice 上 | ★★☆ |
| Box | 好：Box 固定 + Bubble 动态，对比有趣 | ★★☆ |
| Moving Obstacles | 注意：两种动态元素，可能混乱 | ★☆☆ |

## 常见设计错误

1. **气泡方块颜色与周围完全不匹配** → 掉落后也难消除
2. **忘记气泡会移动** → 分析时位置与设计时不同
3. **与 Cage 混淆** → Cage 不动，Bubble 会动
