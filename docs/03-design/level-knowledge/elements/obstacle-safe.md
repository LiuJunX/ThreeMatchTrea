# Safe 保险柜 — 关卡设计指南

## 关卡设计价值

Safe 是"只能用炸弹打"的硬障碍。它强迫玩家制造道具，是策略深度的核心来源：
- **强制道具制造**：普通匹配无效，必须用炸弹/UFO/彩虹球
- **高难度贡献**：每个 Safe 的难度贡献 >> 同等 HP 的 Box
- **区域封锁**：不可穿透，划分棋盘区域

## 属性速查

| 属性 | 值 |
|------|-----|
| 最大 HP | 5 |
| 消除方式 | 仅炸弹/道具（Bomb, Projectile, ChainReaction, ColorBomb, SideItem, ConsumeBomb） |
| 免疫匹配 | ✓ |
| 死亡效果 | 无 |

## 放置原则

### 宜

- **中央偏移**：不在正中央（太容易波及），也不在角落（太难触及）
- **少量精准**：2-4 个就足以制造挑战，多了就 frustrating
- **有 4 消空间的附近**：确保玩家可以在旁边制造炸弹
- **作为"钥匙锁"设计**：Safe 挡住关键路径，玩家必须先制造炸弹开路

### 忌

- **没有 4 消空间的区域**：无法制造道具 = 无法消除 = 死局
- **大面积铺设**：>6 个 Safe 几乎必然造成死局
- **瓶颈处密集放置**：双重阻塞，极难处理
- **全部最高 HP**：5HP 的 Safe 需要 5 次炸弹命中，非常昂贵

### HP 分配建议

| 场景 | 推荐 HP | 说明 |
|------|---------|------|
| 首次出场 | 1-2 | 让玩家理解"需要炸弹" |
| 常规使用 | 2-3 | 核心挑战元素 |
| 高挑战关卡 | 3-5 | 搭配充裕步数 |

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Box | 好：Box 可匹配消开路，Safe 需炸弹精准打 | ★★★ |
| ColorBox | 好：不同消除条件，丰富策略选择 | ★★★ |
| Cage | 可以：先清 Cage 释放方块，再制造炸弹清 Safe | ★★☆ |
| Honey | 危险：Honey 限制移动 + Safe 需要道具 = 双重限制太强 | ★☆☆ |
| Stone | 不推荐：都需要炸弹，对玩家道具需求太高 | ✗ |

## 关键设计规则

**包含 Safe 的关卡，必须验证：**
1. Safe 附近至少有一行/列 ≥4 格连续空间（允许制造火箭）
2. 整体颜色数 ≤6（保证 4 消概率合理）
3. 步数包含道具制造成本（每个 Safe HP ≈ 2-3 步）

## 常见设计错误

1. **Safe 旁边全是障碍** → 无法在旁边制造道具
2. **7 色 + Safe** → 匹配太难，几乎无法制造 4 消
3. **5HP Safe ×4** → 需要 20 次炸弹命中，不现实
4. **首关就引入** → 玩家还不熟悉道具制造
