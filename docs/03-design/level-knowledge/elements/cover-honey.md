# Honey 蜂蜜 — 关卡设计指南

## 关卡设计价值

Honey 是最强的单格控制元素——阻止匹配、交换和移动，且只能通过**相邻消除**才能摧毁：
- **区域封锁**：Honey 格完全不可操作
- **间接消除设计**：需要消除旁边的方块来清除 Honey
- **高难度贡献**：位于角落的 Honey 极难清除

## 属性速查

| 属性 | 值 |
|------|-----|
| 层级 | Cover |
| 默认 HP | 1 |
| 阻止匹配 | ✓ |
| 阻止交换 | ✓ |
| 阻止移动 | ✓ |
| 消除方式 | 相邻方块被消除时扣 HP |

## 放置原则

### 宜

- **有多个相邻可操作格子**：至少 2 个相邻格是可自由操作的
- **中央区域**：容易被相邻消除波及
- **小面积散布**：3-5 个，每个单独处理
- **与 Cage 交替**：Cage 需要炸弹，Honey 需要相邻消除，策略多样

### 忌

- **角落**：角落只有 2 个相邻格，如果这 2 个也被堵 → 无解
- **成片密集**：Honey 群内部的 Honey 无法被清除（没有相邻可操作格）
- **与 Cage 叠加**：同一区域双重封锁 = 死区
- **瓶颈处**：堵死唯一通道

### 核心规则

**每个 Honey 必须至少有 1 个可自由操作的相邻格。**违反此规则 = 死局。

## 组合建议

| 搭配元素 | 效果 | 推荐度 |
|----------|------|--------|
| Box | 好：Box 在 Honey 旁边，消除 Box 顺便清 Honey | ★★★ |
| Ice | 好：Ice 在 Honey 下方，层次丰富 | ★★☆ |
| Cage | 危险：双重封锁，只在有经验后使用 | ★☆☆ |
| Safe | 危险：Safe 需要炸弹，Honey 也难清除，双重压力 | ★☆☆ |

## 常见设计错误

1. **Honey 成 2×2 或更大方块** → 内部 Honey 没有可操作相邻格
2. **角落放 Honey + 相邻格也有障碍** → 理论无解
3. **大量 Honey 包围一个区域** → 无法突破
4. **与 7 色搭配** → 相邻消除概率太低
