# Boss 关设计

## 设计目标

Boss 关是节奏波峰——综合检验玩家当前掌握的机制，提供仪式感和成就感。

## 核心原则

1. **综合检验**：组合多种玩家已见过的元素
2. **多目标**：2-3 个目标，考验全局规划
3. **公平紧张**：步数紧张但可完成，分析胜率 55-70%
4. **视觉冲击**：棋盘丰富、元素种类多，一眼就知道"这关不一样"
5. **有阶段感**：至少包含一种体验模式（决堤/引爆/层层揭开/内外翻转）

## 设计模式

### 围攻
- 外层高 HP 障碍包围
- 中央放核心目标
- 由外向内层层突破

### 分区
- 棋盘分 2-3 个区域
- 每个区域有不同障碍组合
- 目标分布在各区域，需要玩家规划优先级

### 逐层剥离
- 多层覆盖：Ground(Ice) + Cover(Cage) + Obstacle(Box)
- 按层级逐步清除
- 阶段感最强的模式

## 注意事项

- 不能不公平——必须有多条通关路径
- 不能信息过载——虽然元素多，但每种的作用玩家已经理解
- 必须有"开口"——开局就能操作，不能一上来就全被锁死
- 用分析管线验证：胜率不能低于 40%（否则是惩罚不是挑战）
