# 决堤（Dam Break）

## 体验目标

空间释放感 + cascade 狂欢。玩家在有限区域内操作，突然打开新区域，tile 涌入产生大量不可预测的连锁。

## 结构

```
Spawner 行
· · · · · · ·     ← 上半区：正常游戏区
· · · · · · ·
■ ■ ■ ■ ■ ■ ■     ← "堤坝"：一排低 HP 障碍（1-2HP Box）
○ ○ ○ ○ ○ ○ ○     ← 下半区：空白，等待填充
○ ○ ○ ○ ○ ○ ○
```

## 阶段感

1. **上半区（掌控）**：空间小但清晰，玩家在这里消除、制造炸弹
2. **堤坝破裂（惊喜）**：消除波及到障碍行 → 障碍逐个碎裂 → tile 涌入下半区
3. **全场（cascade 不确定性）**：大量新 tile 填充空白区，产生不可预测的连锁

## 心理学对应

- **后果不确定性**：cascade 的结果无法预测 → 多巴胺脉冲
- **空间释放**：从"窄小"到"开阔" → 体感上的解放
- **agency 感**：是玩家的消除打开了堤坝，不是系统自动的

## 适用场景

- 前期关卡（L3-5）：认知成本零，只用 Box
- 任何需要"先紧后松"节奏的关卡
- 搭配收集目标效果好——上半区积累，下半区 cascade 大量收集

## 变体

- **双堤坝**：中间和底部各一排，两次空间释放
- **不均匀堤坝**：中间 HP 高、两侧 HP 低，玩家选择从哪里突破
- **堤坝+预置炸弹**：堤坝后方放炸弹，破坝同时引爆，效果翻倍
- **决堤花园**（Dam + Death Effect）：堤坝行用 Box+Bush 交替排列。破坝后 Bush 死亡 → Grass 在空白区生长，叠加第三层后果："空间释放 + 产物生成 + 新目标出现"。详见 [产出链](production-chain.md)

### 决堤花园数值经验

| 参数 | 建议值 | 原因 |
|------|--------|------|
| KeepEmpty 行数 | ≤ 2 行 | 4 行死锁率 28%，2 行降至 18% |
| Bush 数量 | 3-4 个 | 每个产 4 Grass，3-4 个覆盖足够 |
| Grass 目标 | ≤ 实际产出 × 0.6 | 留容错（空间竞争吃产出） |
| 验证关卡 | `test_pattern_dam_garden.json` | 分析 30.6%（Hard） |
