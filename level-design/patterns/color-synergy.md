# 颜色协同（Color Synergy）

## 体验目标

"红色同时推进了两个不同的目标！"——策略收敛感。多个看似独立的目标通过"颜色"这个隐藏维度对齐，玩家发现后策略从分散收敛为统一。

## 核心原理

颜色是三消中最强的跨元素策略轴。三种颜色相关机制通过"颜色"维度产生深度组合：

| 元素 | 颜色交互方式 | 触发条件 |
|------|------------|---------|
| **ColorBox** | 邻接匹配对应颜色 | 局部 — ColorBox 旁边消目标色 |
| **Curtain** | 全局消除对应颜色 | 全局 — 棋盘上任何位置消目标色 |
| **ColorBomb** | 一次清除所有指定颜色 | 玩家主动 — 与目标色 tile 交换 |

### 颜色三角

三者通过同一种颜色形成策略三角：

```
         ColorBomb(红)
           /        \
    全局清红      清所有红
         /            \
  Curtain(红)    ColorBox(红)
  全局红消除触发    邻接红匹配触发
```

**一次 ColorBomb + 红色交换**：
1. 清除所有红色 tile → Curtain(红) 触发
2. 大量红色消除 → ColorBox(红) 邻接触发概率极高
3. 红色 tile 收集目标也同时推进

## 组合类型

### 单元素颜色发现（入门）

只用 Curtain 或只用 ColorBox，让玩家理解单个元素的颜色规则。

**窗帘终幕**：Curtain 免疫炸弹 → 发现只有颜色消除有效 → 进一步发现 ColorBomb 是终极武器

```
·  W₁ ·  ·  ·  ·  W₁ ·     ← Curtain(Red)
·  ·  ·  ·  ·  ·  ·  ·     ← 大面积消除区（5 色，需要造 ColorBomb）
·  W₂ ·  ·  ·  ·  W₂ ·     ← Curtain(Green)
```

### 双元素颜色对齐（进阶）

同色 Curtain + ColorBox，让玩家发现"一种颜色操作同时推进两种障碍"。

**颜色三角**：左侧 Curtain(Red) + ColorBox(Red)，右侧 Curtain(Green) + ColorBox(Green)

```
·  W₁ ·  ·  ·  ·  W₂ ·     ← Curtain: 红左 / 绿右
·  ·  ·  ·  ·  ·  ·  ·     ← 消除区
·  C₁ ·  ·  ·  ·  C₂ ·     ← ColorBox: 红左 / 绿右（同色垂直对齐）
```

### 颜色三角 + Boss（终极）

三组颜色同时存在，每组各有 Curtain + ColorBox → 需要在 3 种颜色之间切换策略。

## 阶段感

1. **分散处理**：分别尝试处理各个障碍 → 注意力分散 → 步数紧张
2. **发现颜色连接**：偶然匹配一种颜色 → 多个障碍同时反应 → "等等，它们是同色的！"
3. **策略收敛**：集中匹配同色 → 高效同步推进 → "简洁之美"的满足感

## 心理学对应

- **策略收敛的审美体验**：从"多个目标"到"一个维度"的简化过程本身就是奖励
- **ColorBomb 价值升级**：在单元素关卡中 ColorBomb 是"工具"，在颜色三角中升级为"终极武器"——渴望度和制造动机都大幅提升
- **信息发现奖励**：颜色对齐是"隐藏信息"——需要观察 → 推理 → 验证的认知过程

## 适用场景

- **窗帘终幕型**：L15-20，Curtain 首次出场或 ColorBomb 策略深化
- **颜色三角型**：L20+，Curtain + ColorBox 都已出场后的组合关
- **Boss 变体**：L30+，多组颜色三角作为 Boss 关的策略核心

## 设计要点

1. **同色元素垂直对齐**：视觉暗示"它们有关系"，降低发现门槛
2. **HP 全 1**：保证发现效果立竿见影——HP2+ 会模糊因果反馈
3. **4 色棋盘**：保证颜色密度——5 色以上匹配频率下降，ColorBomb 制造困难
4. **不要一次引入太多颜色组**：首次 1 组（单色），进阶 2 组（双色对比），Boss 才 3 组
