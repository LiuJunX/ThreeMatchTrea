# 自教学关卡设计（Self-Teaching）

## 核心理念

**体验即教学**——玩家通过关卡结构自然学会机制，不需要弹窗引导。

如果一个机制需要文字解释才能理解，说明这个机制的视觉语言还不够直观。

## 设计原则

1. **数量最少**：新元素首次只放 1-2 个实例
2. **位置显眼**：放在棋盘中心或必经路径上
3. **目标宽松**：步数充裕，允许试错
4. **周围简单**：新元素附近不放其他复杂元素
5. **结果即时**：操作新元素后立刻看到明显效果
6. **单关新概念 <= 1**：每关最多引入一个玩家之前没见过的元素

## 示例：Honey 首次出场

```
·  ·  ·  ·  ·
·  ·  H  ·  ·     ← 只有 1 个 Honey，正中间
·  ·  ·  ·  ·     ← 周围全是普通 tile
·  ·  ·  ·  ·
目标：消除 30 个某颜色（很宽松）
```

玩家不需要任何提示：
- Honey 挡住了中间的流动 → 自然想消掉它
- 在旁边匹配一次 → Honey 消失 → "哦，原来是这样"
- 只有 1 个 → 试错成本极低

## 与传统教学关的区别

| | 传统教学关 | 自教学关 |
|---|---|---|
| 引导方式 | 弹窗 + 高亮 + 强制操作 | 关卡结构引导 |
| 玩家感受 | "游戏在教我" | "我自己发现的" |
| 认知效果 | 被动接收，容易忘 | 主动发现，记忆深 |
| 对老手 | 烦躁，想跳过 | 自然略过，不打扰 |

## 认知成本分级引入

| 认知成本 | 引入策略 |
|---------|---------|
| 低（Ice、Box） | 首次 1-2 个，最低 HP，旁边可以直接消除 |
| 中（Cage、Honey） | 首次 1 个，放在容易被炸弹波及的位置 |
| 高（MagicHat、ColorBox） | 首次 1 个，目标不要求清除它，让玩家观察它的行为 |

高认知成本元素首次出场时，**不要以它为目标**。让它出现在棋盘上，玩家在追求其他目标的过程中自然观察到它的行为。下一关再以它为目标。
