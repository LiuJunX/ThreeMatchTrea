# 双目标组合设计

## 三种组合类型

### 同向目标（推荐）

两个目标操作上自然协同，完成一个推进另一个。

| 组合 | 机制 |
|------|------|
| 收集红色 + 清除 Ice | 消除红色同时破冰 |
| 清除 Box + 清除 Cage | 炸弹波及两者 |
| 清除 Cupboard + 收集 Plate | 清 Cupboard 释放 Plate |

步数只需覆盖较难的那个目标。体验流畅。

### 中立目标

两个目标互不干扰，需要分配注意力。

| 组合 | 机制 |
|------|------|
| 收集红色 + 收集蓝色 | 分别关注两种颜色 |
| 清除 Ice + 清除 Box | 分布在不同区域 |

将两个目标分布在棋盘不同区域，制造空间规划挑战。

### 冲突目标（谨慎使用）

完成一个目标会阻碍另一个。

| 组合 | 冲突机制 |
|------|---------|
| 收集红色 + ColorBox(红) | 红色消除同时消耗 ColorBox 需要的红色 |
| 清除 Cage + Cage 保护目标方块 | 清 Cage 导致方块掉落移位 |

仅用于高挑战关卡。必须确保理论上可同时完成。

### 行为同向（高级同向）

比"目标同向"更深一层：两个目标的**达成手段**天然重叠，即使目标本身看起来无关。

| 组合 | 行为同向机制 |
|------|------------|
| MagicHat 产 Diamond + Safe 清除 | 在 Safe 旁消除制造炸弹 → 同时给邻接的 MagicHat 充能 |
| 同色 Curtain + ColorBox | 匹配目标色 → 同时推进两种不同机制的障碍 |
| 红色收集 + Curtain(红) | 匹配红色 → 收集 + 触发 Curtain |

区别：
- **目标同向**：完成 A 自然完成 B（如 Cupboard → Plate）
- **行为同向**：达成 A 的**行为**同时推进 B，即使 A 和 B 是完全不同的机制

行为同向是组合关卡设计中最有价值的模式——玩家发现"原来这两个目标可以同时推进"时的认知满足感极强。详见 [颜色协同](color-synergy.md) 和 [间接操作](indirect-operation.md)。

## 设计检查清单

- [ ] 两个目标是同向还是中立？（避免无意冲突）
- [ ] 是否存在行为同向的可能？（提升设计深度）
- [ ] 步数考虑了双目标的总消耗？
- [ ] 玩家能清楚看到两个目标的进度？
- [ ] 可以先完成一个再完成另一个？
