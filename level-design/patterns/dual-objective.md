# 双目标组合设计

## 三种组合类型

### 同向目标（推荐）

两个目标操作上自然协同，完成一个推进另一个。

| 组合 | 机制 |
|------|------|
| 收集红色 + 清除 Ice | 消除红色同时破冰 |
| 清除 Box + 清除 Cage | 炸弹波及两者 |
| 清除 Cupboard + 收集 Plate | 清 Cupboard 释放 Plate |

步数只需覆盖较难的那个目标。体验流畅。

### 中立目标

两个目标互不干扰，需要分配注意力。

| 组合 | 机制 |
|------|------|
| 收集红色 + 收集蓝色 | 分别关注两种颜色 |
| 清除 Ice + 清除 Box | 分布在不同区域 |

将两个目标分布在棋盘不同区域，制造空间规划挑战。

### 冲突目标（谨慎使用）

完成一个目标会阻碍另一个。

| 组合 | 冲突机制 |
|------|---------|
| 收集红色 + ColorBox(红) | 红色消除同时消耗 ColorBox 需要的红色 |
| 清除 Cage + Cage 保护目标方块 | 清 Cage 导致方块掉落移位 |

仅用于高挑战关卡。必须确保理论上可同时完成。

## 设计检查清单

- [ ] 两个目标是同向还是中立？（避免无意冲突）
- [ ] 步数考虑了双目标的总消耗？
- [ ] 玩家能清楚看到两个目标的进度？
- [ ] 可以先完成一个再完成另一个？
