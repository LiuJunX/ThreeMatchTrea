# 内外翻转（Inside Out）

## 体验目标

空间叙事感——"我打开了一个笼子"。玩家从外围操作，打破一个封闭结构，释放内部内容。

## 结构

```
· · · · · · ·
· ■ ■ ■ ■ ■ ·     ← Box 围成的"房间"
· ■ · ★ · ■ ·     ← 内部：预置炸弹或关键目标
· ■ ■ ■ ■ ■ ·
· · · · · · ·
```

## 阶段感

1. **外围（常规）**：在房间外正常消除
2. **破墙（策略）**：选择从哪里打开缺口——侧面？顶部？用炸弹直接炸？
3. **释放（高潮）**：缺口打开 → 内部炸弹被触发 / 内部 tile 加入循环 → 结构瓦解

## 心理学对应

- **好奇心驱动**：看到被围住的东西 → "里面是什么？" → 信息缺口理论
- **策略选择**：从哪里打开是有意义的决策（不同方向影响 cascade 路径）
- **破坏快感**：围墙瓦解的视觉效果天然爽快

## 适用场景

- 中前期关卡（需要 Box 已被玩家理解）
- 需要"空间谜题"感的关卡
- 搭配预置炸弹效果最佳

## 变体

- **多房间**：棋盘上 2-3 个独立的小房间，优先级选择
- **套娃**：大房间里有小房间，两层封闭
- **半透明房间**：用 Ice 而非 Box 围成，玩家能隐约看到内部内容
