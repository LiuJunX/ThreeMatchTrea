# 引爆（Chain Detonation）

## 体验目标

"我做了一件小事，引发了一场大事"——agency 放大感。玩家的一次普通消除触发连锁反应，彻底改变棋盘面貌。

## 结构

```
· · · ★ · · ·     ← ★ = 预置大范围炸弹（Square5x5 或 ColorBomb）
· · ■ ■ ■ · ·     ← 炸弹下方 = 保护层（低 HP Box）
· ■ ■ ■ ■ ■ ·
· · · · · · ·     ← 下方正常区域
· · · · · · ·
```

## 阶段感

1. **底部（热身）**：正常匹配，建立手感
2. **接触保护层（推进）**：消除波及到 Box → Box 碎裂 → 炸弹暴露
3. **引爆（高潮）**：炸弹被触发 → 大范围爆炸 → 棋盘重构

## 心理学对应

- **agency 放大**：小操作 → 大结果，让玩家觉得"我很强"
- **后果不确定性**：爆炸后的 cascade 无法预测
- **叙事弧线**：从"小心翼翼"到"一切炸开"，有清晰的高潮点

## 适用场景

- 可以放在非常早期（L2）——预置炸弹不增加认知负荷
- 需要"爽感"的关卡
- 搭配多颜色收集目标——爆炸一次性清大量

## 变体

- **多炸弹链**：炸弹 A 爆炸波及炸弹 B → B 再爆 → 连环爆炸
- **困在笼中的炸弹**：炸弹被 Cage 锁住，需要先用别的炸弹解锁
- **延迟引爆**：炸弹在棋盘深处，需要多步推进才能触发
