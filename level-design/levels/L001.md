# Level 001 — 决堤初体验

## 速览

| 项目 | 值 |
|------|-----|
| 体验目标 | 玩家在稳定消除中突然经历一次"空间炸开"的 cascade 狂欢 |
| 体验模式 | 空间突变（从心理学推导，非套模板） |
| 棋盘 | 8×8，54 格（底部两角 Void） |
| 步数 | 28 |
| 颜色 | 4 色（TileTypesCount=4） |
| 元素 | 1HP Box ×8（隔层，完全封死） |
| 目标 | 收集 12 红 + 12 蓝 |
| 分析胜率 | Casual 93.0%，挫败风险 0.0%，P95 尝试 2 次 |
| 新概念 | Box（1HP，自解释——视觉不同，碰一下就碎） |

---

## 设计意图

### 情感弧线

```
开局（1-6步）：4色宽裕空间，到处都能消，每步都有正反馈 → 即时胜任感
中盘（7-12步）：消除波及到 Box 行，Box 开始碎裂 → 推进感，"有东西在发生"
转折（~第10-14步）：Box 行大面积碎裂，tile 涌入下方空白区 → 预期违背！
  玩家预期："消 3 个，落下来，继续消"
  实际结果：一次操作引发 20-30 个 tile 的连锁消除
收尾（15-22步）：全场活跃，轻松达成目标 → 从容的成就感
```

### 心理学分析

**预期违背（核心）**

L001 的核心设计点。玩家在前 6-8 步建立心智模型："我的操作规模 = 消除 3-5 个 tile"。
当 Box 行碎裂、tile 涌入空白区时，一次操作突然消除 20-30 个——实际结果远超预期。
这个差距就是多巴胺脉冲的来源。

关键：不预置炸弹。让 cascade 自然在空白区产生 4 连消和 T/L 形，
玩家看到的是"我的操作引发了连锁，连锁又生成了炸弹"，agency 感远强于预置炸弹。

**即时胜任感**

4 色 + 上方 3 行充裕空间 = 开局随便碰哪里都能消。
前 3 步的体验质量决定了玩家对这个游戏的基本印象。
不能出现"开局无可消除"的情况——4 色 + 宽棋盘几乎保证不会。

**基准线校准**

L001 建立"正常"的体验基准。上方 3 行的消除节奏 = 基准。
空间突变是一次性的峰值，不是常态。这样 L002 可以在基准之上做文章，
而不是被 L001 的峰值压住。

### 新手 vs 老手

- **新手**：在上方随意消除 → Box 不知不觉碎了 → tile 涌下来 → "哇好多连消！" → 轻松过关
- **老手**：注意到 Box 行的存在 → 主动在 Box 旁消除加速破坝 → 控制突破时机 → 剩余步数多 → 3 星

## 棋盘设计

```
S  S  S  S  S  S  S  S     ← Row 0: 8 个 Spawner
·  ·  ·  ·  ·  ·  ·  ·     ← Row 1: 正常 Slot（有初始 tile）
·  ·  ·  ·  ·  ·  ·  ·     ← Row 2: 正常 Slot
·  ·  ·  ·  ·  ·  ·  ·     ← Row 3: 正常 Slot
■  ■  ■  ■  ■  ■  ■  ■     ← Row 4: 隔层（8 个 1HP Box，完全封死）
·  ·  ·  ·  ·  ·  ·  ·     ← Row 5: 空 Slot（无初始 tile，等待填充）
·  ·  ·  ·  ·  ·  ·  ·     ← Row 6: 空 Slot
V  ·  ·  ·  ·  ·  ·  V     ← Row 7: 底部两角 Void（微妙的形状感）
```

### 隔层设计细节

- **8 个 Box 完全封死**：不留缺口，底部在决堤前完全空白
- 完全封死的意义：从"零 tile"到"洪水涌入"的对比最极端，预期违背最强
- 留缺口不可行——开放列会持续漏 tile，底部不再是空的，决堤时刻失去对比感
- 1HP = 一次消除波及就碎，不造成任何理解障碍

### 底部 Void 角

- 纯视觉目的：棋盘不是一个死板的矩形，有一点点"设计过"的感觉
- 对玩法几乎没有影响（只少了 2 格）
- 暗示"棋盘形状是可以变化的"→ 为后续关卡的异形棋盘铺垫

## 关键决策记录

1. **不预置炸弹**：选择让 cascade 自然生成炸弹，而非预置。因为自然生成的 agency 感更强，且避免了"底部炸弹被提前触发"的时机不可控问题。
2. **隔层完全封死**：选择 8 Box 无缺口。留缺口会导致 tile 持续漏下，底部不再空白，决堤对比感消失。完全封死 → 从零到洪水的极端对比。
3. **4 色而非 5 色**：L001 的重点是手感和惊喜，不是挑战。4 色保证高匹配密度和 cascade 丰富度。
4. **双色收集目标**：20 红 + 20 蓝，而非单色。两个目标让玩家有最低限度的"关注点"，但 4 色 + 大 cascade 下极易完成。
5. **28 步**：原始设计 22 步在 6 色系统下 Casual 胜率仅 34%（目标 20+20 太高）。调整为 12+12 / 28 步后 Casual 80.5%、挫败风险 1.0%、P95 尝试 2 次。
6. **底部 Void 角**：纯视觉设计感，功能影响极小。向玩家暗示"棋盘不总是矩形"。

---

## 修改指南

- **动这里会破坏体验**：隔层必须是 1HP（高了会变成"障碍关"不是"体验关"）；必须 4 色（5 色会降低 cascade 密度，削弱决堤时刻的冲击力）
- **安全调参区间**：步数 25-30 可调；目标数量 8-15 每色可调（6色系统下 20+ 太高）
- **已知边界**：隔层必须 8 格全封（留缺口会导致 tile 持续漏下，底部无法保持空白）

### 系统改动记录

为支持 L001 设计，新增了两个系统特性：
1. **LevelConfig.TileTypesCount**：允许每关指定颜色数（4色），不再受全局默认值（6色）限制
2. **ElementType.KeepEmpty**：Grid 数组中标记"初始空格"，底部 3 行开局无 tile，实现真正的"决堤"效果
