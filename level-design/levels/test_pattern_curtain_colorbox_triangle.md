# Pattern: Color Triangle — 颜色三角

## 速览

| 项目 | 值 |
|------|-----|
| 体验目标 | 玩家发现同色 Curtain + ColorBox 通过"颜色"形成策略三角 |
| 体验模式 | 多元素协同型 |
| 棋盘 | 8×8，64 格 |
| 步数 | 20 |
| 颜色 | 4 色 |
| 元素 | Curtain(Red) ×1 + Curtain(Green) ×1 + ColorBox(Red/HP1) ×1 + ColorBox(Green/HP1) ×1 |
| 目标 | 清除 2 Curtain + 清除 2 ColorBox |
| 分析胜率 | Population 23.6%（Hard） |
| 新概念 | 颜色作为跨元素协同轴 — 一次操作多重收益 |

---

## 设计意图

### 核心发现

同色的 Curtain + ColorBox 形成天然策略三角：

```
         ColorBomb(Red)
           /        \
          /          \
   Curtain(Red)  ColorBox(Red)
   全局红消除      邻接红匹配
```

三者通过"红色"连接：
- **匹配红色** → ColorBox(Red) 邻接受伤 + 红色 Curtain 的全局颜色消除计数 +1
- **ColorBomb + 红色** → 全局清所有红 → Curtain(Red) 直接触发 + ColorBox(Red) 可能被覆盖
- **一次操作，三个收益**

**Aha! 时刻**: "红色同时推进 Curtain 和 ColorBox！ColorBomb + 红色一波三杀！"

### 情感弧线

```
开局（1-5步）：分别尝试消除 Curtain 和 ColorBox → 发现两者有不同规则
中盘（6-12步）：偶然匹配红色 → 发现 Curtain 和 ColorBox 同时反应 → 顿悟
转折（~第10步）：理解"颜色是连接轴" → 开始主动匹配同色
收尾（13-20步）：如果造出 ColorBomb → 一波清完同色障碍组 → 极度满足
```

### 心理学分析

**策略收敛（核心）**

多目标通常意味着注意力分散。但当多个目标通过同一维度（颜色）对齐时，
策略反而收敛 — "只要持续做红色相关的操作就好"。
从分散 → 收敛的认知过程本身产生"简洁之美"的审美体验。

**ColorBomb 的终极价值**

在单元素关卡中，ColorBomb 只是"清一种颜色"。
在颜色三角中，ColorBomb 升级为"一次操作触发整条协同链"的终极武器。
这个价值升级让玩家对 ColorBomb 的渴望度和制造动机都大幅提升。

### 新手 vs 老手

- **新手**：分别处理 Curtain 和 ColorBox → 分散注意力 → 步数紧张
- **老手**：识别颜色连接后集中匹配同色 → 高效同步推进 → 步数富余

## 棋盘设计

```
S  S  S  S  S  S  S  S     ← Row 0: Spawner
·  ·  ·  ·  ·  ·  ·  ·     ← Row 1
·  W₁ ·  ·  ·  ·  W₂ ·     ← Row 2: Curtain(Red)左 + Curtain(Green)右
·  ·  ·  ·  ·  ·  ·  ·     ← Row 3-5: 中间消除区
·  ·  ·  ·  ·  ·  ·  ·
·  ·  ·  ·  ·  ·  ·  ·
·  C₁ ·  ·  ·  ·  C₂ ·     ← Row 6: ColorBox(Red)左 + ColorBox(Green)右
·  ·  ·  ·  ·  ·  ·  ·     ← Row 7
```

### 布局逻辑

- 同色 Curtain 和 ColorBox 垂直对齐（同列 col 1/6）：视觉暗示"它们有关系"
- Curtain 在上方（Row 2），ColorBox 在下方（Row 6）：空间分离但颜色对齐
- 左侧红色组，右侧绿色组：两个独立的颜色三角，降低初次接触的认知负载
- 中间 3 行空旷：给 ColorBomb 制造留足空间

### 颜色三角推导

```
左侧组（红色）：
  Curtain(Red, Row 2, Col 1) — 需要红色全局消除
  ColorBox(Red, Row 6, Col 1) — 需要邻接红色匹配
  → 匹配红色：两者同时受益
  → ColorBomb + 红色交换：Curtain 秒杀 + 大量红消除覆盖 ColorBox

右侧组（绿色）：
  同理，绿色操作同时推进两个目标
```

---

## 关键决策记录

1. **同色 Curtain+ColorBox 垂直对齐**：视觉布局暗示"颜色关系"，降低发现门槛
2. **双色组而非单色组**：增加策略选择 — 先攻红色组还是绿色组？
3. **HP 全 1**：保证发现效果立竿见影。HP2+ 会让反馈太慢，模糊因果关系
4. **无额外 tile 收集目标**：纯障碍目标，让玩家 100% 专注于颜色策略

---

## 修改指南

- **动这里会影响体验**：同色 Curtain+ColorBox 的配对是核心。拆开颜色配对 = 失去协同体验
- **安全调参区间**：步数 18-25 可调。可增至每色 2 个（共 8 个障碍）提高难度
- **已知边界**：Curtain 的触发靠全局颜色消除频率，4 色保证了足够的颜色密度
- **进阶版**：加入第三种颜色的 Curtain+ColorBox → 三组三角同时处理 → Boss 关素材
