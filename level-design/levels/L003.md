# Level 003 — 连环炸

## 速览

| 项目 | 值 |
|------|-----|
| 体验目标 | 多次爆炸的节奏感，发现"不同炸弹效果不同" |
| 棋盘 | 8×7，四角缺口（~52 格） |
| 步数 | 12 |
| 颜色 | 4 色 |
| 元素 | 预置 HorizontalRocket ×1 + VerticalRocket ×1 |
| 目标 | 收集 8 红 + 8 绿 + 8 蓝 |
| 分析胜率 | 待验证 |
| 新概念 | 火箭类炸弹（行清除 vs 列清除，L002 是方炸弹） |

---

## 设计意图

### 情感弧线

```
开局（第1步）：棋盘上方有一个横火箭，很显眼 → 点击 → 整行清除！ → "原来这个是横着炸的"
节奏（第2-4步）：cascade + 正常消除 → 收集进度跳动
第二波（第3-5步）：棋盘下方有一个纵火箭 → 点击 → 整列清除！ → "这个是竖着炸的，不一样！"
收尾（6-12步）：4色高密度消除 → 轻松达成目标
```

### 心理学分析

**模式识别快感**

人类大脑天然奖励"发现规律"。当玩家点了横火箭看到清行，再点纵火箭看到清列，
大脑自动归纳："横的清行，竖的清列"。这个"啊，我懂了"的瞬间就是模式识别带来的满足感。

不需要任何文字说明——两次不同的视觉结果就是最好的教学。

**节奏感（间歇强化）**

L002 是"一次大爆炸就结束"。L003 是"砰→消→砰→消"的节奏。
两次爆炸之间有几步正常消除作为"呼吸"，让每次爆炸都有独立的冲击感，
而不是糊成一片。

### 新手 vs 老手

- **新手**：看到发光方块 → 点第一个 → "哇横着全没了" → 点第二个 → "竖着也行！" → 轻松过关
- **老手**：看到两个火箭 → 理解它们的效果 → 可能先做几步消除制造更好的 cascade 环境 → 再点火箭最大化收益 → 剩余步数多

## 棋盘设计

```
V  ·  ·  ·  ·  ·  ·  V     ← Row 0: 四角缺口
·  ·  ·  🚀h ·  ·  ·  ·     ← Row 1: 横火箭在 (3,1)
·  ·  ·  ·  ·  ·  ·  ·     ← Row 2
·  ·  ·  ·  ·  ·  ·  ·     ← Row 3
·  ·  ·  ·  ·  ·  ·  ·     ← Row 4
·  ·  ·  ·  🚀v ·  ·  ·     ← Row 5: 纵火箭在 (4,5)
V  ·  ·  ·  ·  ·  ·  V     ← Row 6: 四角缺口
```

### 火箭位置设计

- **横火箭 (3,1)**：靠近顶部，玩家自然先看到、先操作
- **纵火箭 (4,5)**：靠近底部，在横火箭的 cascade 后露出或更容易注意到
- 两个火箭**不相邻**：防止玩家误触发组合（L004 才教组合）
- 位置偏中心：确保爆炸效果覆盖大量 tile

---

## 关键决策记录

1. **两种不同火箭而非两个相同的**：目的是让玩家发现"不同炸弹效果不同"，为 L004 铺垫。
2. **火箭不相邻**：避免意外触发炸弹组合。L003 的目标是"分别体验"，不是"组合"。
3. **8×7 而非 8×8**：比 L001/L002 矮一行，给玩家一个"棋盘大小会变化"的感受，且 7 行让关卡更紧凑。
4. **4 色 + 3 目标各 8 个**：和 L002 类似的收集感，但目标略低因为棋盘略小。
5. **12 步**：序章节奏要快。点两个火箭 + 几步收集就够了。

---

## 修改指南

- **动这里会破坏体验**：两个火箭必须是不同类型（一横一纵）；不能相邻（防组合）
- **安全调参区间**：步数 8-15 可调；每色目标 5-10 可调
- **已知边界**：如果火箭在同行/同列，一个火箭的爆炸可能消灭另一个（链式激活），这对 L003 来说太早——确保火箭不在同行同列
